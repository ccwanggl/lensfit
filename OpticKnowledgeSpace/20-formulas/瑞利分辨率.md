# 瑞利分辨率

> 瑞利分辨率（Rayleigh Resolution）基于瑞利判据，给出圆形孔径光学系统刚好能分辨的两个点之间的最小角距离：θ ≈ 1.22 λ / D，其中 λ 为波长，D 为入瞳直径。在显微镜和望远镜中，瑞利分辨率是衡量极限分辨能力的核心指标。
