# 棱镜色散率

## 公式

棱镜的**角色散率**（Angular Dispersion）表示单位波长变化引起的偏向角变化：

```
dθ / dλ = (dn / dλ) · (dθ / dn)
```

对于最小偏向角条件下的对称光路，角色散率可简化为：

```
dθ / dλ = (t · dn/dλ) / a
```

其中：
- `t`：棱镜底边长度（光在棱镜内部传播的有效底边长度）
- `a`：入射光束宽度（或出射光束宽度）
- `dn/dλ`：棱镜材料的色散率（折射率对波长的导数）

棱镜的**理论分辨本领**（Resolving Power）R 为：

```
R = t · |dn/dλ|
```

或更精确地：

```
R = b · |dn/dλ|
```

其中 `b` 为棱镜底边长度（与 t 含义相同）。

## 变量与单位

| 变量 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 角色散率 | dθ/dλ | rad/nm 或 °/nm | 单位波长变化引起的角度变化 |
| 材料色散率 | dn/dλ | 1/nm | 折射率随波长的变化率，由材料决定 |
| 棱镜底边长度 | t 或 b | mm | 棱镜底边（光传播方向）的长度 |
| 光束宽度 | a | mm | 入射（或出射）光束宽度 |
| 分辨本领 | R | 无量纲 | 理论光谱分辨率 |

## 适用条件

- 公式基于棱镜工作在**最小偏向角条件**（对称光路），此时分辨率最高。
- 假设棱镜被光束完全照亮（即光束宽度等于或小于棱镜通光孔径）。
- 实际分辨率受狭缝宽度、像差、光源宽度等限制，理论 R 是上限。
- 色散率 `dn/dλ` 强烈依赖于波长和材料（正常色散区：短波色散更强）。

## 推导或解释

1. 棱镜的偏向角 θ 与折射率 n 有关：θ = f(n)。
2. 根据几何光学和斯涅尔定律，在最小偏向角条件下：
   ```
   dθ/dn = t / a
   ```
   其中 t 为棱镜底边，a 为光束宽度。
3. 根据链式法则：
   ```
   dθ/dλ = (dθ/dn) · (dn/dλ) = (t / a) · (dn/dλ)
   ```
4. 分辨本领 R = λ/Δλ，由瑞利判据和干涉理论推导，最终得到：
   ```
   R = t · |dn/dλ|
   ```

关键结论：棱镜分辨率与底边长度和材料色散率成正比，与光束宽度无关（但光束宽度影响角色散率的表达式）。

## 验证样例

**样例**：使用重火石玻璃棱镜，底边长度 t = 50 mm，在 λ = 589 nm 处 dn/dλ ≈ -0.0001 nm⁻¹（负号表示正常色散，取绝对值）。

- 理论分辨本领：
  ```
  R = t · |dn/dλ| = 50 mm × 0.0001 nm⁻¹ = 50,000
  ```
- 在 λ = 589 nm 处的最小可分辨波长差：
  ```
  Δλ = λ / R = 589 nm / 50,000 ≈ 0.0118 nm ≈ 11.8 pm
  ```

**对比（与光栅对比）**：
- 光栅 1200 线/mm × 50 mm 宽，一级：R = 60,000
- 棱镜 50 mm 底边，高色散玻璃：R ≈ 50,000
- 棱镜分辨率通常与光栅相当，但棱镜色散是非线性的（短波色散强），而光栅色散近似线性。
