# 普朗克黑体辐射公式

## 公式

### 普朗克辐射定律（光谱辐射出射度）

单位波长、单位面积的辐射功率：

```
B(λ, T) = (2hc² / λ⁵) · 1 / (exp(hc / λkT) - 1)
```

或按频率表示：

```
B(ν, T) = (2hν³ / c²) · 1 / (exp(hν / kT) - 1)
```

其中：
- `h`：普朗克常数 ≈ 6.626 × 10⁻³⁴ J·s
- `c`：光速 ≈ 2.998 × 10⁸ m/s
- `k`：玻尔兹曼常数 ≈ 1.381 × 10⁻²³ J/K
- `λ`：波长（单位 m）
- `T`：绝对温度（单位 K）
- `B(λ, T)`：光谱辐射出射度（单位 W·sr⁻¹·m⁻³）

### 维恩位移定律（简化形式）

黑体辐射光谱峰值波长 λ_max 与温度 T 的关系：

```
λ_max = b / T
```

其中 `b ≈ 2.898 × 10⁻³ m·K = 2898 μm·K`（维恩位移常数）。

| 变量 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 普朗克常数 | h | J·s | 6.626 × 10⁻³⁴ J·s |

| 维恩常数 | b | μm·K | 2898 μm·K |

## 适用条件

- 适用于**理想黑体**（吸收率 = 1，发射率 = 1）。
- 实际光源（白炽灯、太阳、LED）发射率 < 1，光谱形状与黑体近似但不同。
- 色温定义基于黑体辐射：光源的 SPD 与某温度黑体最接近时，该温度为光源色温。
- 维恩位移定律仅给出峰值波长，不给出峰值强度。
- 普朗克公式在全部波长范围有效；瑞利-金斯公式和维恩公式是其长波/短波近似。

## 推导或解释

1. 黑体是理想化的热辐射体，与物质无关，只取决于温度。
2. 普朗克在 1900 年假设能量是量子化的（E = hν），成功推导出了与实验完全吻合的黑体辐射公式。
3. 这是量子力学的诞生点之一。
4. 对普朗克公式在全波长积分，得到斯特藩-玻尔兹曼定律（总辐射功率 ∝ T⁴）。
5. 对普朗克公式求导并令导数为零，得到维恩位移定律。

## 验证样例

**样例 1（维恩位移定律）**：太阳表面温度约 5778 K，求辐射峰值波长。

```
λ_max = 2898 μm·K / 5778 K ≈ 0.5016 μm = 501.6 nm
```

结果在可见光绿区，符合太阳光谱特征。

**样例 2**：白炽灯色温 2700 K，求辐射峰值波长。

```
λ_max = 2898 / 2700 ≈ 1.07 μm = 1070 nm
```

峰值在近红外，可见光部分只是长波尾巴，因此白炽灯光效低、偏暖黄。

**样例 3（色温与黑体）**：D65 标准照明体色温 6504 K。

```
λ_max = 2898 / 6504 ≈ 0.446 μm = 446 nm
```

峰值在蓝光区，光谱更均衡，因此 D65 用于色彩评价标准光源。
