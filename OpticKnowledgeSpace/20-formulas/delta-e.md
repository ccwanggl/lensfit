# Delta E 色差

## 公式

CIE 1976（Lab）色彩空间中的色差公式（CIE76）：

```
ΔE = √( (ΔL)² + (Δa)² + (Δb)² )
```

其中：
- `ΔL = L₂ - L₁`：明度差
- `Δa = a₂ - a₁`：绿-红轴色差
- `Δb = b₂ - b₁`：蓝-黄轴色差

更精确的改进公式（如 CIE94 或 CIE2000）考虑了人眼对不同色区的感知不均匀性，但 CIE76 是最基础、最常用的形式。

## 变量与单位

| 变量 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 明度 | L* | 无量纲 | 0（纯黑）~ 100（纯白） |
| 绿-红轴 | a* | 无量纲 | 负值为绿，正值为红 |
| 蓝-黄轴 | b* | 无量纲 | 负值为蓝，正值为黄 |
| 色差 | ΔE | 无量纲 | 两个颜色在 Lab 空间中的欧氏距离 |

## 适用条件

- 适用于 CIE 1976 L*a*b*（Lab）色彩空间。
- 两种颜色应在相近照明条件、相同标准观察者下测量。
- ΔE 是**感知色差**的近似度量，不是物理量。
- 工业中通常指定 ΔE 容差（如 ΔE < 1.0）来控制颜色一致性。

## 推导或解释

1. CIE 1931 XYZ 色彩空间不是视觉均匀的（相同距离不对应相同感知差异）。
2. CIE 1976 Lab 色彩空间通过非线性变换使空间近似视觉均匀：
   ```
   L* = 116 f(Y/Yn) - 16
   a* = 500 [f(X/Xn) - f(Y/Yn)]
   b* = 200 [f(Y/Yn) - f(Z/Zn)]
   ```
   其中 Xn, Yn, Zn 是参考白点，f 为非线性函数。
3. 在 Lab 空间中，用欧氏距离近似感知色差。

## 验证样例

**ΔE 的感知意义**（经验判断标准）：

| ΔE 范围 | 人眼感知 | 应用场景 |
|---------|----------|----------|
| ΔE < 1.0 | 人眼**不可分辨** | 高端印刷、显示校准 |
| 1.0 ≤ ΔE < 3.0 | **小差异**，可察觉但可接受 | 一般工业颜色容差 |
| 3.0 ≤ ΔE < 5.0 | **明显差异**，可轻松分辨 | 颜色质量警告 |
| ΔE ≥ 5.0 | **大差异**，显著不同颜色 | 不合格 |

**计算样例**：

颜色 1: L₁ = 50, a₁ = 20, b₁ = 30（橙色）
颜色 2: L₂ = 52, a₂ = 22, b₂ = 33（稍亮偏红的橙色）

```
ΔL = 52 - 50 = 2
Δa = 22 - 20 = 2
Δb = 33 - 30 = 3

ΔE = √(2² + 2² + 3²) = √(4 + 4 + 9) = √17 ≈ 4.12
```

**判断**：ΔE ≈ 4.12，属于“明显差异”范围，人眼可轻松分辨。
