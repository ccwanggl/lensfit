# 光栅方程

## 公式

光栅方程描述了平面光栅衍射中入射光与衍射光的角度关系：

```
d (sin θi + sin θm) = m λ
```

或对于反射光栅（入射与衍射在光栅法线同侧）：

```
d (sin θi - sin θm) = m λ
```

其中：
- `d`：光栅常数（相邻刻线间距，单位 nm）
- `θi`：入射角（相对于光栅法线）
- `θm`：第 m 级衍射角（相对于光栅法线）
- `m`：衍射级次（整数，0, ±1, ±2, ...）
- `λ`：入射光波长（单位 nm）

## 变量与单位

| 变量 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 光栅常数 | d | nm | 相邻刻线间距，d = 1 / (刻线密度) |
| 入射角 | θi | 度 (°) | 入射光束与光栅法线夹角 |
| 衍射角 | θm | 度 (°) | 第 m 级衍射光与光栅法线夹角 |
| 衍射级次 | m | 无量纲 | 整数，0 级为镜面反射，±1 级为常用工作级次 |
| 波长 | λ | nm | 入射光波长 |

光栅常数与刻线密度关系：
```
d (nm) = 10⁶ / (刻线密度，线/mm)
```
例如：1200 线/mm → d ≈ 833.3 nm

## 适用条件

- **平面光栅**：公式适用于平面刻划或全息光栅。
- **入射光为单色光或复色光**：复色光中不同波长在同一级次有不同衍射角。
- **m = 0**：零级衍射为镜面反射，无色散（θi = θm）。
- **|mλ/d| ≤ 2**：由于 sin 函数最大值为 1，存在可衍射的波长上限。
- 对于透射光栅，公式形式相同，但角度定义需调整。

## 推导或解释

1. 光栅可看作大量等间距狭缝（或反射面）。
2. 相邻刻线衍射光的光程差为 `Δ = d (sin θi + sin θm)`。
3. 根据干涉加强条件（相长干涉），光程差必须等于波长的整数倍：
   ```
   Δ = m λ
   ```
4. 由此得到光栅方程。

光栅的核心作用：将不同波长光在不同角度分散开来，实现光谱分离。

## 验证样例

**样例 1**：刻线密度 1200 线/mm，入射角 θi = 0°（正入射），求 λ = 500 nm 的一级衍射角。

- d = 10⁶ / 1200 = 833.3 nm
- m = 1，λ = 500 nm
- sin θ₁ = mλ / d = 500 / 833.3 = 0.6
- **θ₁ ≈ 36.9°**

**样例 2**：判断 λ = 800 nm 光在上述光栅中能否产生一级衍射。

- sin θ₁ = 800 / 833.3 = 0.96 < 1
- 可以衍射，θ₁ ≈ 73.7°

**样例 3**：λ = 900 nm 时，sin θ₁ = 900 / 833.3 = 1.08 > 1，无法产生一级衍射。
