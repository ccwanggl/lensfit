# 光栅光谱分辨率

## 公式

光栅的光谱分辨本领（Resolving Power）R 定义为：

```
R = λ / Δλ = m N
```

其中：
- `λ`：中心波长
- `Δλ`：可分辨的最小波长差（恰可分辨判据）
- `m`：衍射级次
- `N`：光栅总刻线数（N = 刻线密度 × 光栅有效宽度）

## 变量与单位

| 变量 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 中心波长 | λ | nm | 待分辨的谱线中心波长 |
| 最小可分辨波长差 | Δλ | nm | 瑞利判据下两条谱线恰好可分辨的间隔 |
| 分辨本领 | R | 无量纲 | 波长与最小波长差之比，越大分辨率越高 |
| 衍射级次 | m | 无量纲 | 使用的衍射级次（常用 1 或 2） |
| 总刻线数 | N | 无量纲 | 光栅被照亮区域的总刻线数 |

## 适用条件

- 适用于平面光栅和凹面光栅的光谱仪。
- 假设入射光均匀照亮整个光栅宽度。
- 实际分辨率还受狭缝宽度、探测器像素尺寸、光学像差等限制，因此 **理论 R = mN 是上限**。
- 高衍射级次（m > 1）可提高分辨率，但光强降低且级次重叠问题更严重。

## 推导或解释

光栅分辨率来源于多光束干涉的锐条纹特性：
1. 光栅有 N 条刻线，相当于 N 束光的干涉。
2. 干涉主极大的角宽度约为 `Δθ ≈ λ / (N d cos θ)`。
3. 根据瑞利判据，当一个峰的主极大落在另一个峰的第一极小处时，两峰恰好可分辨。
4. 结合光栅方程微分，可导出 `R = m N`。

结论：分辨率与总刻线数成正比，与光栅尺寸（而非刻线密度单独）直接相关。

## 验证样例

**样例**：光栅规格为 1200 线/mm，光栅有效宽度 50 mm，使用一级光谱（m = 1），求理论分辨本领和在 500 nm 处的最小可分辨波长差。

- 刻线密度 = 1200 线/mm
- 光栅宽度 = 50 mm
- 总刻线数 N = 1200 × 50 = 60,000
- 衍射级次 m = 1
- **理论分辨本领 R = m N = 1 × 60,000 = 60,000**
- 在 λ = 500 nm 处：
  ```
  Δλ = λ / R = 500 nm / 60,000 ≈ 0.0083 nm ≈ 8.3 pm
  ```

**对比**：如果改用 600 线/mm、同样 50 mm 宽的光栅：
- N = 600 × 50 = 30,000
- R = 30,000（一半）
- Δλ = 500 / 30,000 ≈ 0.0167 nm（分辨率降低一倍）

**如果改用二级光谱（m = 2）**：
- R = 2 × 60,000 = 120,000
- Δλ = 500 / 120,000 ≈ 4.2 pm
- 但光强降低，且需解决级次重叠问题。
