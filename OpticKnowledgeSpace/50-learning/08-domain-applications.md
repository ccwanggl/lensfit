> "学完理论之后，真正的考验是：面对一个真实问题，你能不能把之前学的知识串起来，做出正确的选择。"

---

## 8.1 工业视觉

### 场景特征

| 特征 | 说明 |
|------|------|
| 目标 | 检测、测量、识别 |
| 工作距离 | 固定或有限范围（100mm–2m 常见） |
| 光源 | 人工控制（LED、频闪、激光） |
| 精度要求 | 高，通常需要亚像素级 |
| 成本敏感 | 批量部署，性价比重要 |

### 核心匹配逻辑

**步骤1：根据检测精度反推像素精度**

$$
\text{像素精度} \leq \frac{\text{检测精度}}{3 \sim 5}
$$

> 例如：要求检测 0.05mm 的缺陷 → 像素精度应 ≤ 0.01–0.017 mm/px

**步骤2：由像素精度反推放大倍率**

$$
\beta = \frac{p}{1000 \times \text{像素精度}}
$$

> 像元 3.45μm，像素精度 0.01mm/px → β = 3.45/(1000×0.01) = 0.345×

**步骤3：由视场和工作距离求焦距**

$$
f = \frac{WD \cdot s}{FOV + s}
$$

**步骤4：检查像圈覆盖**

传感器对角线 ≤ 镜头像圈 × 0.95

**步骤5：检查奈奎斯特匹配**

镜头 MTF50 应在传感器奈奎斯特频率的 0.5–1.2 倍之间

### 典型配置速查

| 应用 | 传感器 | 镜头 | 精度 |
|------|--------|------|------|
| PCB 焊点检测 | 2/3" 5MP, 3.45μm | 35mm 远心, WD=150mm | ~10μm/px |
| 零件尺寸测量 | 1" 12MP, 3.2μm | 50mm 大靶面, WD=500mm | ~30μm/px |
| 高速缺陷检测 | 1/2" 2MP, 4.5μm | 25mm, 全局快门 | ~100μm/px |

## 8.2 摄影

### 场景特征

| 特征 | 说明 |
|------|------|
| 目标 | 艺术创作、记录 |
| 工作距离 | 多变，从微距到无限远 |
| 光源 | 自然光为主 |
| 精度要求 | 主观审美，无硬性指标 |
| 系统复杂 | 镜头 + 机身 + 后期流程 |

### 焦段选择速查

| 焦段 | 视角 | 用途 | 透视特点 |
|------|------|------|---------|
| 14–24mm | 超广角 | 风景、建筑、星空 | 强烈透视，边缘拉伸 |
| 35–50mm | 标准 | 人文、日常 | 接近人眼自然视角 |
| 85–135mm | 中长焦 | 人像、特写 | 压缩空间，背景虚化 |
| 200mm+ | 长焦 | 体育、野生动物 | 强烈空间压缩 |

### 景深控制的艺术

| 效果 | 参数组合 |
|------|---------|
| 背景虚化（人像） | 长焦 + 大光圈 + 近对焦 |
| 全景深（风景） | 广角 + 小光圈 + 超焦距对焦 |
| 微距全景深 | 微距镜头 + 小光圈 + 焦点包围 |

### 画幅选择

| 画幅 | 优势 | 劣势 |
|------|------|------|
| 全画幅 | 高感好、景深浅、镜头群丰富 | 体积大、价格高 |
| APS-C | 轻便、长焦等效系数 | 高感弱、广角受限 |
| M4/3 | 极轻便、防抖强 | 高感更弱、景深更深 |

> **画幅的物理本质**：更大的传感器 = 更大的总进光量 = 更好的信噪比。同等技术下，全画幅的动态范围和高感比 APS-C 好约 1 档（2 倍）。

## 8.3 显微镜

### 场景特征

| 特征 | 说明 |
|------|------|
| 目标 | 观察微小结构 |
| 工作距离 | 极短（高倍物镜 < 1mm） |
| 光源 | 透射（明场）或反射（金相） |
| 精度要求 | 由 NA 决定的理论极限 |
| 系统组成 | 物镜 + 镜筒透镜 + 目镜/相机 |

### 分辨率极限

瑞利判据：

$$
d = \frac{0.61 \cdot \lambda}{NA}
$$

| NA | 理论分辨率 (@550nm) | 用途 |
|----|--------------------|------|
| 0.25 | 1.34 μm | 低倍观察 |
| 0.65 | 0.52 μm | 常规生物 |
| 0.90 | 0.37 μm | 高倍干式 |
| 1.40 | 0.24 μm | 油浸最高 |

### 数码显微镜的像素匹配

传感器采样间距应满足：

$$
\frac{\text{像元尺寸}}{M_{物镜} \cdot M_{适配器}} \leq \frac{0.61 \cdot \lambda}{NA \cdot 2.3}
$$

> 示例：NA=0.65，λ=0.55μm，光学分辨率 = 0.52μm
> 理想采样间距 = 0.52/2.3 ≈ 0.23μm
> 若适配器 1×，物镜 40×，所需像元尺寸 = 0.23 × 40 = **9.2μm**
> 因此 6.5μm 像元的 sCMOS 略有欠采样，3.45μm 像元则过采样。

## 8.4 红外成像

### 场景特征

| 特征 | 说明 |
|------|------|
| 目标 | 温度测量、夜视、穿透烟雾 |
| 波段 | LWIR (8–14μm) 或 MWIR (3–5μm) |
| 镜头材料 | 锗 (Ge)、ZnSe、硫系玻璃 |
| 探测器 | VOx 微测辐射热计、MCT、InGaAs |
| 特殊要求 | 无热化设计、发射率校正 |

### 热成像分辨率

空间分辨率由 IFOV 决定：

$$
IFOV = \frac{\text{像元尺寸}}{f} \quad [mrad]
$$

$$
\text{空间分辨率} = IFOV \times WD \quad [m]
$$

> 像元 17μm，焦距 19mm，WD=10m：
> IFOV = 17/19 = 0.895 mrad，空间分辨率 = 8.95mm

### NETD 与测温精度

| NETD | 灵敏度 | 应用 |
|------|--------|------|
| < 30 mK | 极高 | 医学、科研 |
| 30–50 mK | 高 | 工业测温、建筑检测 |
| 50–80 mK | 中 | 安防监控 |

> **发射率是关键**：不同材料的辐射率差异巨大。抛光金属（ε≈0.1）和氧化金属（ε≈0.8）在相同温度下，热像仪读数可能差数倍。

## 快速检查 ✓

**Q1**：工业检测要求 0.02mm 精度，使用像元 3.45μm 的相机，需要多大的放大倍率？
<details>
<summary>点击展开答案</summary>

像素精度目标 = 0.02/5 = 0.004 mm/px

$$
\beta = \frac{3.45}{1000 \times 0.004} = 0.86×
$$

需要约 0.86× 的放大倍率。

</details>

**Q2**：显微镜 60×/1.40 油浸物镜，配 1× 适配器，要达到理想采样，需要多大像元的相机？
<details>
<summary>点击展开答案</summary>

光学分辨率 = 0.61 × 0.55 / 1.40 = 0.24 μm

理想采样间距 = 0.24 / 2.3 ≈ 0.104 μm

所需像元尺寸 = 0.104 × 60 × 1 = **6.24 μm**

因此像元 6.5μm 的 sCMOS 非常接近理想匹配。

</details>

**Q3**：热成像相机像元 12μm，焦距 13mm，在 5m 距离上的空间分辨率是多少？
<details>
<summary>点击展开答案</summary>

IFOV = 12/13 = 0.923 mrad

空间分辨率 = 0.923 × 5 = **4.6 mm**

即每个像素代表 5m 距离上约 4.6mm 的物理尺寸。

</details>
