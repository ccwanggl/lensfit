# 学习教程

推荐从 [[../90-maps/001-Learning Path|从零到深入学习路径]] 开始，而不是直接随机打开章节。

## 阶段目标

| 阶段 | 学完后应该具备的能力 |
|---|---|
| 第0-4章 | 看懂光学系统的基本组成，理解镜头和传感器的核心参数 |
| 第5-9章 | 完成基础镜头-传感器匹配，并能判断常见选型错误 |
| 第10-13章 | 理解衍射、像质、光学设计和照明对成像质量的影响 |
| 第14-15章 | 把光学、算法和工程约束放在一起做系统取舍 |
| 第16章 | 从颜色进入光谱，理解多光谱、高光谱、光谱仪和色彩管理 |
