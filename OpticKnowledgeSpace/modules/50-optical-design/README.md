## 核心概念（15个）

| 概念 | 说明 |
|------|------|
| 像差（波前） | 实际波前与理想球面波前的偏差，描述成像偏离理想状态的量 |
| Spot diagram | 大量光线通过系统后在像面上的落点分布图，直观反映几何像差 |
| Ray fan | 入瞳处同一子午面内不同高度光线在像面上的垂轴像差曲线 |
| OPD | 光程差，波前像差的直接度量，单位通常为波长 |
| 波前误差 | 实际波前与参考波前的光程差，常用 RMS 值和 PV 值表征 |
| Zernike 多项式 | 定义在单位圆上的正交多项式，用于描述和拟合波前像差 |
| MTF | 调制传递函数，表征系统对不同空间频率的对比度传递能力 |
| 畸变 | 放大率随视场变化导致的图像几何变形，与视场三次方成正比 |
| 照度 | 像面单位面积接收的光通量，通常随视场角四次方衰减（cos⁴定律） |
| 优化目标函数 | 光学设计软件中用于驱动系统向理想状态收敛的数学评价函数 |
| 评价函数 | 由多个像质指标加权构成的综合评分函数，用于比较设计方案 |
| 容差 | 制造和装调过程中允许的几何和光学参数偏差范围 |
| 灵敏度 | 系统像质对某一参数变化的敏感程度，决定容差严格度 |
| 设计变量 | 优化过程中可自由调整的系统参数（如曲率、厚度、材料等） |
| 公差分析 | 模拟制造误差和装调误差对系统像质的综合影响，验证可制造性 |

## 三本账指引

- **概念账**：理解"规格驱动设计"的核心理念：从需求（焦距、F数、视场、波长、分辨率）出发选择初始结构类型，通过像质评价指标（Spot diagram、Ray fan、OPD、MTF）诊断问题，用 Zernike 多项式解读波前像差成分。掌握公差分析的意义：设计不仅是理论最优，更要可制造、可装调、可量产。
- **计算账**：能计算 Seidel 像差系数，理解各像差对成像的具体影响。会读取 Spot diagram 和 MTF 曲线，从几何像差预测 MTF 趋势。理解优化目标函数的构建逻辑：设置约束（如总长、后焦距、边缘厚度）和优化目标（如 RMS spot size、MTF@特定频率）。能进行基本的蒙特卡洛公差分析，评估系统良率。
- **项目账**：完成「光学系统设计全流程」项目——从给定的需求规格（如 25mm 焦距、F/2.8、1" 传感器、可见光波段）出发，选择初始结构，进行优化迭代，评价像质（Spot diagram + MTF），制定公差表，并撰写可制造性评估报告。
