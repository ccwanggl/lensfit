# 模块戊｜光学设计与像质评价 — 项目清单

本模块包含 5 个实践项目，从需求规格到优化设计、像质评价和公差分析，覆盖光学设计的完整闭环。

---

## 项目 1：光学系统设计全流程

- **目标**：从给定的需求规格（如 25 mm 焦距、F/2.8、1" 传感器、可见光波段）出发，在 Zemax/Code V 中选择初始结构，进行优化迭代，评价像质（Spot diagram + MTF），制定公差表，并撰写可制造性评估报告。
- **预计时间**：6–8 小时
- **所需工具**：Zemax OpticStudio（或 Code V/OSLO 试用版）、镜头专利数据库、玻璃库
- **产出物**：
  - 需求规格表（EFL、F/#、FOV、传感器、波长、后工作距离）
  - 初始结构选择与理由
  - 优化后的镜头数据表（曲率、厚度、材料、空气间隔）
  - Spot diagram、Ray fan、OPD 图、MTF 曲线
  - 优化前后的像质对比
  - 公差表（曲率、厚度、偏心、倾斜、折射率）
  - 蒙特卡洛公差分析结果（良率预测）
  - 可制造性评估报告
- **与模块内容的关联**：完整实践"规格—结构—分析—优化—容差"的设计闭环，是模块戊的核心综合项目。

## 项目 2：Zernike 像差分析与可视化

- **目标**：从 Zemax 或干涉仪数据中提取 Zernike 系数，分解各阶像差成分，计算对应的 RMS WFE 和 Strehl 比，绘制波前图和点扩散函数。
- **预计时间**：3–4 小时
- **所需工具**：Zemax（波前图功能）、MATLAB/Python（Zernike 可视化）、或干涉仪实测数据
- **产出物**：
  - Zernike 系数表（前 11 项或前 37 项）
  - 各阶像差（离焦、像散、彗差、球差）的波前图
  - RMS WFE 计算过程与结果
  - Strehl 比估算（Marechal 近似与精确积分对比）
  - 像差校正建议（如"增加一片非球面以校正球差"）
- **与模块内容的关联**：深入理解 Zernike 多项式、波前误差、Strehl 比之间的关系，建立像差诊断和量化能力。

## 项目 3：MTF 测量与像质诊断

- **目标**：使用商用 MTF 测试设备或自制刀口/狭缝法，测量实际镜头的 MTF 曲线，与 Zemax 仿真 MTF 对比，分析差异原因（装调误差、制造公差、测量误差）。
- **预计时间**：3–4 小时
- **所需工具**：分辨率测试板（USAF 1951 或 Siemens 星）、精密平移台、高分辨率相机、图像处理软件
- **产出物**：
  - 实测 MTF 曲线（切向/弧矢）
  - Zemax 仿真 MTF 曲线
  - 实测 vs 仿真对比图
  - 差异来源分析（至少 3 项）
  - 改进建议（如重新装调、更换公差更严格的元件）
- **与模块内容的关联**：验证 MTF 作为像质评价指标的工程价值，理解仿真与实测之间的鸿沟及原因。

## 项目 4：非球面/自由曲面优化探索

- **目标**：在 Zemax 中为一个简单的双透镜系统引入非球面或自由曲面，比较优化前后的像质提升，分析非球面带来的制造复杂度与成本权衡。
- **预计时间**：3–4 小时（可选，进阶）
- **所需工具**：Zemax OpticStudio（非球面/自由曲面优化功能）
- **产出物**：
  - 球面系统 vs 非球面系统的像质对比（Spot diagram、MTF、RMS WFE）
  - 非球面系数表与面形描述
  - 非球面加工可行性评估（如是否可用标准单点金刚石车削）
  - 成本-性能权衡分析
- **与模块内容的关联**：理解现代光学设计中非球面和自由曲面的价值，建立"像质提升 vs 制造可行性"的工程权衡思维。

## 项目 5：照明系统设计优化

- **目标**：设计一个针对特定被测物体的照明系统（如均匀照明面光源或远心照明），优化照明均匀性和集光效率，评估照明-成像系统的耦合性能。
- **预计时间**：3–4 小时（可选，进阶）
- **所需工具**：Zemax（非序列模式）或 LightTools，LED 光源规格表
- **产出物**：
  - 照明系统需求（均匀性要求、区域大小、工作距离）
  - 光源-透镜-目标面的光路设计
  - 照明均匀性模拟结果（均匀性百分比、辐照度分布图）
  - 集光效率估算
  - 与成像系统的匹配分析（如照明 NA 与成像 NA 的关系）
- **与模块内容的关联**：将模块乙的照明几何概念与模块戊的优化设计能力结合，完成照明-成像系统的联合设计。

---

## 项目选择建议

- **必修**：项目 1（光学设计全流程）、项目 2（Zernike 像差分析）
- **推荐**：项目 3（MTF 测量与诊断）
- **选修**：项目 4（非球面优化）、项目 5（照明设计）
- 完成必修项目后，建议至少再完成 1 个推荐项目，方可进入综合项目阶段。
