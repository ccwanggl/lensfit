# 模块甲｜桥接 — 项目清单

本模块为知识库入口，项目以"建立直觉"和"熟悉工具"为主，不涉及复杂光学系统搭建。

---

## 项目 1：搭建简易光学平台

| 项目 | 说明 |
|------|------|
| **目标** | 使用 LED 光源、单透镜和 CCD/手机摄像头，验证薄透镜公式和放大率公式 |
| **预计时间** | 3–5 h |
| **所需工具** | LED 光源、单凸透镜（焦距已知）、直尺、CCD 或手机、固定支架 |
| **产出物** | 物距-像距数据表、放大率实测 vs. 理论对比图、简易光路照片 |
| **关联内容** | 薄透镜公式、放大率、焦距、数值孔径、F 值 |

**关键步骤**：
1. 测量透镜焦距（太阳光法或公式法）。
2. 固定物距，改变像距，找到清晰成像位置，记录数据。
3. 改变物距，重复测量，验证 $1/f = 1/u + 1/v$。
4. 测量物高与像高，验证 $M = v/u$。
5. 估算系统的 NA 和 F 值，与理论值对比。

## 项目 2：折射率测量实验

| 项目 | 说明 |
|------|------|
| **目标** | 用斯涅尔定律测量水或玻璃的实际折射率 |
| **预计时间** | 2–3 h |
| **所需工具** | 激光笔、半圆柱玻璃/水盒、量角器、白纸 |
| **产出物** | 入射角-折射角数据表、折射率拟合值、误差分析 |
| **关联内容** | 折射率、斯涅尔定律、光速、波长与频率 |

**关键步骤**：
1. 激光以不同角度入射到介质表面。
2. 测量折射角，绘制 $\sin\theta_i$ vs. $\sin\theta_r$ 曲线。
3. 拟合斜率得到折射率 $n$。
4. 与标准值对比，分析误差来源（表面不平整、角度测量误差等）。

## 项目 3：光谱基础探索

| 项目 | 说明 |
|------|------|
| **目标** | 用手机光谱仪 App 或简易棱镜观察不同光源的光谱 |
| **预计时间** | 2–3 h |
| **所需工具** | 手机光谱仪 App（如 SpectraSnapp）或玻璃棱镜、日光/LED/荧光灯/钠灯 |
| **产出物** | 不同光源的光谱照片、谱线特征标注、色温估算 |
| **关联内容** | 波长、频率、光子能量、色温、光谱分布 |

**关键步骤**：
1. 观察日光的连续光谱。
2. 观察 LED 的窄带光谱，估算中心波长。
3. 观察荧光灯的线状光谱（汞发射线）。
4. 观察钠灯的双黄线（589.0/589.6 nm）。

## 项目 4：单位换算速查表制作

| 项目 | 说明 |
|------|------|
| **目标** | 制作光学常用单位换算速查表，建立"数值直觉" |
| **预计时间** | 1–2 h |
| **所需工具** | Python/Jupyter、NumPy |
| **产出物** | 个人单位换算速查表（Markdown 或打印版）、典型数值记忆卡 |
| **关联内容** | 波长、频率、能量、折射率、数值孔径、F 值 |

**关键步骤**：
1. 列出常用换算：nm ↔ eV、μm ↔ cm⁻¹、deg ↔ rad、lp/mm ↔ μm 等。
2. 计算并记忆典型值：500 nm ≈ 2.48 eV，可见光范围 400–700 nm 等。
3. 用 Python 验证换算关系，制作交互式换算器。
