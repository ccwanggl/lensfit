# 模块甲｜桥接

## 模块目标

建立光学分析的语言基础与物理直觉，打通物理光学与工程光学的概念桥梁。

## 先修知识

无。本模块为知识库入口，面向所有背景读者。

## 核心概念（10个）

| 概念 | 说明 |
|------|------|
| [[../10-concepts/refractive-index\|折射率]] | 光在介质中传播速度相对于真空的比值 |
| [[../10-concepts/wavelength\|波长]] | 光波一个完整周期对应的空间长度 |
| [[../10-concepts/frequency\|频率]] | 单位时间内光波振动的次数 |
| [[../10-concepts/photon-energy\|能量]] | 单个光子的能量，与频率成正比 |
| [[../10-concepts/speed-of-light\|光速]] | 真空中约为 299,792,458 m/s |
| [[../10-concepts/thin-lens\|薄透镜]] | 厚度可忽略的理想化透镜模型 |
| [[../10-concepts/focal-length\|焦距]] | 平行光线经透镜汇聚点到光心的距离 |
| [[../10-concepts/magnification\|放大率]] | 像高与物高之比，描述成像缩放 |
| [[../10-concepts/numerical-aperture\|数值孔径]] | 衡量光学系统集光能力的无量纲参数 |
| [[../10-concepts/f-number\|F值]] | 焦距与入瞳直径之比，表征通光量 |

## 三本账指引

> 每个模块均从「概念账」「计算账」「项目账」三个维度推进学习。

- **概念账**：理解上述10个核心概念的物理意义、相互关系及工程语境中的使用场景。每个概念笔记应包含定义、物理直觉、图示与常见误区。
- **计算账**：掌握折射定律、薄透镜公式、放大率公式、数值孔径与F值的计算。能根据给定参数推导光路基本特性。
- **项目账**：完成「搭建简易光学平台」迷你项目——使用LED光源、单透镜和CCD，测量焦距、验证放大率公式，并记录NA与F值的实测对比。
