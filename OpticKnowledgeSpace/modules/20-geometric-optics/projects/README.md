# 模块乙｜几何光学与一阶成像 — 项目清单

本模块项目聚焦"用光线模型解决实际成像问题"，从手动追迹到软件辅助设计逐步深入。

---

## 项目 1：一阶光学系统设计

| 项目 | 说明 |
|------|------|
| **目标** | 根据传感器尺寸、工作距离和视场要求，选择焦距、计算 F 值与景深，绘制光路草图 |
| **预计时间** | 5–8 h |
| **所需工具** | 计算器或 Python/Jupyter、纸笔 |
| **产出物** | 设计报告（含焦距计算、F 数选择、景深估算、光路草图）、镜头-传感器匹配分析 |
| **关联内容** | 焦距、F 值、视场、景深、NA、放大率、匹配基础 |

**关键步骤**：
1. 给定需求：1/2" 传感器、工作距离 200 mm、视场 100 mm。
2. 计算所需焦距：$f = \frac{WD \cdot h_{sensor}}{FOV + h_{sensor}}$。
3. 根据分辨率要求选择 F 值（兼顾通光量和景深）。
4. 估算景深：$DoF \approx \frac{2u^2 N c}{f^2}$（$N$ 为 F 数，$c$ 为弥散圆直径）。
5. 绘制光路草图，标注入瞳、出瞳、主光线位置。
6. 评估像差校正需求（是否需要消色差双胶合）。

## 项目 2：镜头-传感器匹配分析

| 项目 | 说明 |
|------|------|
| **目标** | 为给定的工业镜头和传感器组合，判断匹配是否合适，计算覆盖率和奈奎斯特极限 |
| **预计时间** | 3–5 h |
| **所需工具** | 镜头规格书、传感器数据手册、Python（可选） |
| **产出物** | 匹配分析报告、分辨率对比表、匹配建议 |
| **关联内容** | 像圈、像素精度、奈奎斯特频率、放大率、匹配基础 |

**关键步骤**：
1. 读取镜头规格：像圈、焦距、F 值、分辨率（MTF@xx lp/mm）。
2. 读取传感器规格：像素尺寸、分辨率、传感器尺寸。
3. 计算放大率：$M = \text{sensor size} / \text{FOV}$。
4. 计算像素精度：$\text{Pixel Precision} = \text{Pixel Size} / M$。
5. 计算奈奎斯特频率：$f_N = 1 / (2 \cdot \text{Pixel Size})$。
6. 对比镜头 MTF@$f_N$ 与传感器需求，判断是否匹配。

## 项目 3：像差观察与分类

| 项目 | 说明 |
|------|------|
| **目标** | 使用简单透镜（如放大镜）观察不同位置的像差，识别球差、彗差、像散、色差 |
| **预计时间** | 4–6 h |
| **所需工具** | 单透镜、双胶合透镜、彩色物体（如色卡）、网格靶标、CCD/手机 |
| **产出物** | 像差对比照片、分类说明、双胶合校正效果对比 |
| **关联内容** | 球差、彗差、像散、场曲、畸变、色差、双透镜 |

**关键步骤**：
1. 球差观察：单透镜对点光源成像，对比中心和边缘光线的聚焦位置。
2. 色差观察：用白光照射，观察像的彩色边缘。
3. 彗差观察：轴外点光源，观察彗星状拖尾。
4. 像散观察：轴外网格靶，观察子午和弧矢方向聚焦差异。
5. 对比双胶合透镜的色差校正效果。

## 项目 4：RayOptics 仿真入门

| 项目 | 说明 |
|------|------|
| **目标** | 使用 RayOptics 软件建立简单透镜系统，追迹光线并分析 Spot diagram |
| **预计时间** | 4–6 h |
| **所需工具** | Python + RayOptics 库（`pip install rayoptics`） |
| **产出物** | Jupyter 笔记本（含光路图、Spot diagram、ray fan 图）、分析报告 |
| **关联内容** | 近轴近似、像差、孔径光阑、入瞳/出瞳、Spot diagram、ray fan |

**关键步骤**：
1. 安装并运行 RayOptics，建立单透镜模型。
2. 追迹不同视场和孔径的光线，生成 Spot diagram。
3. 改变透镜形状（双凸 vs. 平凸），观察像差变化。
4. 添加光阑，分析入瞳/出瞳位置。
5. 尝试双胶合透镜，对比色差校正效果。

## 项目 5：照明几何设计

| 项目 | 说明 |
|------|------|
| **目标** | 为机器视觉场景设计照明方案（同轴/低角度/远心），分析均匀性和阴影 |
| **预计时间** | 4–6 h |
| **所需工具** | LED 光源、漫射板、半透半反镜、被测样品（如 PCB、金属件） |
| **产出物** | 三种照明方式下的样品照片、均匀性分析、最优方案选择理由 |
| **关联内容** | 同轴照明、低角度照明、远心照明、漫射、镜面反射、半影、均匀性 |

**关键步骤**：
1. 同轴照明：观察镜面反射和表面细节。
2. 低角度照明：突出边缘和纹理（如划痕、凸起）。
3. 远心照明：配合远心镜头，分析阴影和透视畸变。
4. 对比不同照明下的图像质量，记录均匀性和对比度。
