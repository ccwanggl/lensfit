# 第13章（下）光源光谱特性与色温

> "光谱是光的『身份证』——不同光源的『指纹』截然不同，决定了颜色还原的真实性。"

---

## 13.1 直觉：为什么光谱和色温一样重要？

照明设计的四大维度中，**光谱**直接决定了颜色还原是否真实。一个光源可能非常亮、非常均匀，但如果它的光谱在红色波段有缺口，那么红色物体在该光源下看起来就会偏暗或偏色。这在颜色检测、食品分级、纺织品色差控制等场景中尤为关键。

工业视觉系统必须「看见」真实的颜色，而非被光源扭曲后的颜色。因此，光源的光谱特性（Spectral Power Distribution, SPD）与色温选择，是照明设计中与几何布局同等重要的另一根支柱。

> **核心目标**：选择光谱覆盖被测颜色反射波段、色温稳定、显色性高的光源。

---

## 13.2 光源类型

### 直觉：不同灯像不同乐器的音色

光源不是只有「亮」和「暗」的区别。就像钢琴、小提琴、电吉他都能发出中央C音，但音色完全不同——不同光源的「光谱指纹」也截然不同。

### LED（发光二极管）—— 工业视觉的主角

**为什么 LED 是主流？**

- **寿命极长**：50,000–100,000 小时，连续工作数年不老化
- **发热低**：比卤素灯低 80% 以上，不需要强制散热
- **响应快**：纳秒级开关，适合频闪控制
- **光谱可控**：通过荧光粉和滤色片调整色温与显色性

**关键参数**：

| 参数 | 符号 | 含义 | 典型值 |
|------|------|------|--------|
| **色温** | $T_c$ | 光源颜色的冷暖程度 | 3000K（暖白）– 6500K（冷白） |
| **显色指数** | CRI | 还原物体真实颜色的能力 | 80（一般）– 98（专业） |
| **光谱半宽** | Δλ | 单色 LED 的波长范围 | 10–40 nm |

> **注意**：普通白光 LED 是蓝光芯片 + 黄色荧光粉的组合，光谱在蓝光区域有一个尖峰，在红区有缺失。这对颜色检测不是好消息。高 CRI LED 通过补充红磷粉来填补缺口，但效率略低。

### 卤素灯（Halogen）—— 连续光谱的坚守者

**优点**：
- 光谱连续平滑，像黑体辐射曲线，显色性极好（CRI ≈ 100）
- 色温稳定（约 3200K），偏暖黄

**缺点**：
- 发热巨大，90% 能量变成热量
- 寿命短，2000–5000 小时
- 色温固定，不适合需要冷白光的场景

> **应用场景**：对颜色还原要求极高的领域（如纺织色差检测、艺术品复制），以及需要连续光谱的分光测量。

### 激光 / 线激光（Laser）—— 单色与相干

**优点**：
- 单色性极好，波长带宽 < 1 nm
- 方向性强，可聚焦到极细线宽（微米级）
- 亮度极高，适合远距离或弱反射场景

**缺点**：
- **相干散斑（Speckle）**：激光照射粗糙表面时，光程差导致干涉图样，图像出现颗粒状噪声
- 人眼安全等级要求高（尤其 Class 3B 以上）
- 成本高

> **应用场景**：3D 结构光扫描、线激光轮廓测量、精密对准。散斑问题可通过旋转散射器或多模光纤部分缓解。

### 频闪光源（Strobe）—— 冻结时间的光

不是独立的光源类型，而是指任何光源配合短时脉冲驱动（通常是 LED 或氙灯）。

- **脉宽**：μs 到 ms 级
- **峰值亮度**：可达连续模式的 10–100 倍
- **发热**：平均功率低，因为大部分时间不发光

> **工业价值**：在高速产线上，频闪可以把运动物体「冻结」在图像中，避免运动模糊。同时减少发热，延长 LED 寿命。

### 选择光源的决策树

```
需要频闪/高速冻结？
  ├─ 是 → LED + 频闪驱动器（或氙灯频闪）
  └─ 否 → 需要极高颜色还原？
        ├─ 是 → 卤素灯 或 高 CRI LED（CRI > 95）
        └─ 否 → 需要线/结构光？
              ├─ 是 → 线激光或 LED 线光源
              └─ 否 → 通用白光 LED（性价比最高）
```

## 13.3 光谱特性在工程中的影响

### 普通白光 LED 的颜色陷阱

普通白光 LED 由蓝光芯片 + 黄色荧光粉组成。其光谱特征为：
- 蓝光区（450 nm 附近）有一个强尖峰
- 黄绿区（550 nm 附近）有荧光粉发射
- 红区（> 600 nm）光谱能量显著不足

红色物体主要反射红光（600–700 nm）。由于普通白光 LED 在这个区域的光谱功率低，反射到相机的光就少，导致红色物体看起来偏暗，颜色不饱和。这在颜色检测（如印刷品、纺织品、食品成熟度）中是致命缺陷。

### 高 CRI LED 的补救机制

高 CRI LED 通过添加红磷粉，补充了 600–700 nm 区域的光谱能量，使光谱更连续、更接近黑体辐射。这样所有颜色的物体都能获得与其反射光谱匹配的光照，颜色还原更真实。

> **工程启示**：做颜色检测时，务必确认光源光谱覆盖被测颜色的主要反射波段，不要只看「亮不亮」。

### 色温漂移与可重复性

LED 的色温会随着老化、温度变化和驱动电流变化而漂移。工业测量要求可重复性，因此：
- 使用恒流驱动器，而非恒压驱动，减少电流波动导致的色温变化
- 对颜色敏感的应用，在光源达到热平衡后再进行标定
- 必要时使用反馈式色温监控（如集成色温传感器）

## 13.4 常见误区：光谱与颜色检测

### 误区：「一种白光 LED 搞定所有颜色检测」

**错误**：认为只要是「白光 LED」，颜色检测就没问题。

**事实**：
- 普通白光 LED 在红区光谱缺失，红色物体检测会系统性偏暗
- 不同批次 LED 的荧光粉配比不同，色温和光谱可能有差异
- 光源老化后，蓝光芯片效率下降比荧光粉快，光谱会「变黄」

> **正确做法**：颜色检测任务必须选择高 CRI 光源（CRI > 90），并定期做色彩标定。对极端颜色检测（如肤色、食品成熟度），考虑使用卤素灯或窄带 LED 组合照明。

### 误区：忽略光源光谱与被测物反射光谱的匹配

**错误**：只关注光源的色温和亮度，不关心被测物体在哪些波段反射最多光。

**事实**：
- 如果光源在某波段能量低，而物体恰好主要反射该波段，则图像信噪比（SNR）会系统性偏低
- 在荧光检测中，激发光的光谱必须覆盖荧光物质的吸收峰
- 在多光谱/高光谱成像中，窄带光源的选择直接决定了能提取哪些特征

> **正确做法**：分析被测物体的反射光谱（或荧光激发光谱），与光源的 SPD 做卷积估算，确保关键波段有足够的光能量。必要时使用光谱仪测量实际光源输出。
