# 模块丁｜光谱学与光谱仪

## 模块目标

掌握光谱原理、仪器结构（光栅/棱镜分光系统）和分辨率限制，理解色散、光谱分辨率与探测器响应的完整链条。

## 核心概念（15个）

| 概念 | 说明 |
|------|------|
| 色散 | 介质折射率随波长变化导致不同色光分离的现象 |
| 光谱分辨率 | 仪器区分两条相邻谱线的能力，$R = \lambda / \Delta\lambda$ |
| 光栅方程 | 描述光栅衍射角与波长、级次关系的方程 |
| 光栅分辨率 | 光栅分光能力的理论极限，$R = mN$ |
| 棱镜色散率 | 棱镜角色散或线色散，描述单位波长差引起的分离程度 |
| 阿贝数 | 表征光学材料色散程度的倒数指标，数值越大色散越小 |
| 色温 | 描述光源颜色特性的等效黑体温度，单位开尔文 |
| 色度图 | 用二维坐标表示人眼可感知的所有颜色范围的图表（如 CIE 1931） |
| 荧光 | 物质吸收短波长光后发射较长波长光的辐射过程 |
| 拉曼散射 | 光与分子相互作用导致频率偏移的非弹性散射 |
| 多光谱成像 | 在少数几个离散波段获取图像的技术 |
| 高光谱成像 | 在大量连续窄波段获取图像的技术，形成"数据立方体" |
| Czerny-Turner | 一种经典的光栅光谱仪结构，采用两个球面反射镜 |
| 狭缝 | 限制入射光宽度以控制光谱纯度和分辨率的关键孔径 |
| 探测器响应 | 探测器对不同波长光的灵敏度曲线，决定系统有效光谱范围 |

## 三本账指引

- **概念账**：理解色散的物理起源（材料色散与波导色散）。掌握光栅光谱仪与棱镜光谱仪的结构差异和适用场景。理解狭缝宽度对光通量与光谱分辨率之间的权衡。建立色度图上的颜色空间直觉。
- **计算账**：能运用光栅方程计算特定波长和级次的衍射角。能计算光栅分辨率 $R = mN$ 和棱镜的极限分辨率。理解阿贝数与色散的关系 $V_d = (n_d - 1)/(n_F - n_C)$。能进行基本的色度计算（CIE 三刺激值、Delta E 色差）。
- **项目账**：完成「简易光谱仪设计」项目——选择光栅参数和探测器，计算所需光谱范围对应的衍射角范围，评估狭缝宽度对分辨率的影响，绘制系统光路草图并确定探测器放置位置。
