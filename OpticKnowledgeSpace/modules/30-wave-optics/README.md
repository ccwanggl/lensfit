# 模块丙｜波动光学与傅里叶成像

## 模块目标

从"光线为什么不够"切入，理解干涉、衍射、相干、PSF/OTF/MTF、傅里叶光学，建立从波动模型到成像质量的完整认知链条。

## 先修知识

- [[../20-geometric-optics/README|模块乙｜几何光学与一阶成像]]（必修）

## 核心概念（15个）

| 概念 | 说明 |
|------|------|
| 干涉 | 两束或多束相干光波叠加产生强度重新分布的现象 |
| 衍射 | 光波遇到障碍物或孔径时偏离直线传播的现象 |
| 相干 | 光波之间具有确定相位关系，能够产生稳定干涉图样的特性 |
| 艾里斑 | 圆孔衍射产生的中央亮斑，决定理想光学系统的极限分辨率 |
| 瑞利判据 | 两个等强度点光源刚好能被分辨的判据标准 |
| PSF | 点扩散函数，理想系统对点光源的响应，反映成像的极限模糊 |
| OTF | 光学传递函数，描述系统对不同空间频率的复振幅传递能力 |
| MTF | 调制传递函数，OTF 的模值，表征对比度随空间频率的衰减 |
| 傅里叶变换 | 将空域信号分解为空间频率成分的数学工具 |
| 空间频率 | 单位长度内亮度变化的周期数，单位为 lp/mm |
| 截止频率 | 系统能够传递的最高空间频率，超过此频率的信息丢失 |
| 相位物体 | 主要引起光波相位变化而非振幅变化的透明样品 |
| 振幅物体 | 主要引起光波振幅（强度）吸收或反射的物体 |
| 空间滤波 | 在傅里叶频域中选择性地通过或阻挡特定空间频率成分 |
| 全息 | 记录并再现光波振幅和相位信息的完整成像技术 |

## 三本账指引

- **概念账**：理解光线模型在干涉、衍射场景下的失效原因。掌握相干条件、时间相干性与空间相干性的区别。建立"空域—频域"对应直觉：PSF 是空域描述，OTF/MTF 是频域描述，两者通过傅里叶变换关联。理解相位物体与振幅物体在成像中的不同表现。
- **计算账**：能计算双缝干涉条纹间距、光栅衍射角、艾里斑半径和瑞利分辨极限。会进行简单的傅里叶变换对运算（如矩形函数↔sinc函数、高斯函数↔高斯函数）。理解 MTF 曲线读取：在特定空间频率处的对比度保留率。
- **项目账**：完成「衍射极限分析」项目——使用已知波长和孔径参数，计算理论艾里斑尺寸和截止频率，与几何光学预测的分辨率进行对比，撰写"何时波动光学不可忽略"的判断准则。
