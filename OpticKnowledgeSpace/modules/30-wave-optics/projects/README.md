# 模块丙｜波动光学与傅里叶成像 — 项目清单

本模块包含 5 个实践项目，从基础波动光学实验到傅里叶光学系统搭建，帮助学习者建立从波动模型到成像质量的完整认知。

---

## 项目 1：双缝干涉与相干条件验证

- **目标**：搭建双缝干涉装置，观察干涉条纹，改变光源的线宽（滤光片）和扩展程度（狭缝宽度），验证时间相干性和空间相干性的影响。
- **预计时间**：2–3 小时
- **所需工具**：激光笔（或钠灯+滤光片）、双缝片（不同缝间距）、光屏/CCD、光具座、可调狭缝
- **产出物**：
  - 不同缝宽/缝间距下的干涉条纹照片
  - 条纹间距测量数据与理论计算对比
  - 光源扩展对条纹可见度影响的观察记录
- **与模块内容的关联**：直接验证干涉、相干条件、时间相干性和空间相干性概念，建立波动光学的实验直觉。

## 项目 2：衍射极限分析

- **目标**：使用已知波长和孔径参数（圆孔或矩形孔），计算理论艾里斑尺寸和截止频率，并与几何光学预测的分辨率进行对比，撰写"何时波动光学不可忽略"的判断准则。
- **预计时间**：2–3 小时
- **所需工具**：激光光源、可调光阑（不同孔径）、成像屏/相机、直尺
- **产出物**：
  - 不同孔径下的衍射斑测量照片与尺寸测量
  - 理论艾里斑半径计算表
  - 几何光学分辨率 vs 波动光学分辨率对比图
  - "何时波动光学不可忽略"的判断准则（含 F数、NA、波长、特征尺寸的判据）
- **与模块内容的关联**：综合运用衍射极限、艾里斑、瑞利判据、截止频率等概念，建立波动光学与几何光学的边界判断能力。

## 项目 3：PSF/OTF/MTF 测量实验

- **目标**：使用刀口法或狭缝法测量成像系统的线扩散函数（LSF），通过数值计算得到 MTF 曲线，并与理论衍射受限 MTF 对比。
- **预计时间**：3–4 小时
- **所需工具**：成像系统（镜头+相机）、精密刀口/狭缝、平移台、图像处理软件（Python/MATLAB）
- **产出物**：
  - 刀口扩散函数（ESF）原始数据
  - 数值微分得到的 LSF 曲线
  - 傅里叶变换得到的 MTF 曲线
  - 与理论衍射受限 MTF 的对比分析
- **与模块内容的关联**：理解 PSF→OTF→MTF 的转换链条，建立"空域—频域"对应直觉。

## 项目 4：4f 空间滤波系统搭建

- **目标**：搭建简易 4f 光学系统，在傅里叶面上放置不同空间滤波器（低通、高通、方向滤波），观察并记录输出图像的变化。
- **预计时间**：3–4 小时
- **所需工具**：两个相同焦距的透镜（f = 50–100 mm）、激光光源、针孔滤波器、准直透镜、空间滤波掩模（自制或购置）、光屏/CCD
- **产出物**：
  - 4f 系统光路照片
  - 不同滤波器（低通/高通/方向）的输入/输出图像对比
  - 滤波器传递函数描述与效果分析
- **与模块内容的关联**：验证傅里叶变换对、4f 系统、空间滤波等核心概念，建立频域操作的物理直觉。

## 项目 5：部分相干成像模拟

- **目标**：使用 MATLAB 或 Python，模拟不同相干度（σ = 0, 0.5, 1.0）照明下的成像过程，观察部分相干对 MTF 和图像对比度的影响。
- **预计时间**：3–4 小时（编程项目）
- **所需工具**：电脑、Python（NumPy/SciPy）或 MATLAB
- **产出物**：
  - 部分相干成像模拟代码
  - 不同 σ 值下的模拟成像结果图
  - 部分相干 MTF 与相干/非相干 MTF 的对比曲线
  - 结论：部分相干照明对成像的实际影响
- **与模块内容的关联**：深入理解相干度对成像系统的综合影响，为光刻、显微成像等应用建立理论基础。

---

## 项目选择建议

- **必修**：项目 2（衍射极限分析）、项目 3（PSF/MTF 测量）
- **推荐**：项目 1（干涉实验）、项目 4（4f 系统）
- **选修**：项目 5（编程模拟，进阶）
- 完成必修项目后，建议至少再完成 1 个推荐项目，再进入模块戊。
