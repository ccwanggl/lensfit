# 知识库扩展计划

## 当前状态

`50-learning/` 已有10章完整的入门教程（绪论→习题），质量较高。但：

- **深度不足**：只覆盖到基础匹配和像差，没有物理光学进阶、傅里叶光学、光学设计、计算光学等深入内容。
- **原子笔记缺失**：`10-concepts/`、`20-formulas/`、`40-devices/` 基本为空，没有建立 Obsidian 双链网络。
- **实践环节薄弱**：没有工程案例、选型实战、问题诊断等实践内容。
- **知识地图未激活**：虽有地图，但下游节点大多缺失。

## 目标：构建「入门→进阶→深入→实践」的完整路径

### 阶段1：扩展学习路径（新增进阶+深入+实践章节）

| 新增章节 | 内容 | 定位 |
|---------|------|------|
| 第10章 物理光学深入 | 干涉、衍射、相干成像、全息 | 进阶 |
| 第11章 光学设计基础 | 光阑、光瞳、镜头结构、像差校正、设计流程 | 进阶 |
| 第12章 光学传递函数与图像质量 | OTF、PSF、MTF测量、SNR、色彩科学 | 进阶 |
| 第13章 照明系统设计 | 光源类型、照明方式、均匀性、偏振 | 进阶 |
| 第14章 计算光学与计算成像 | 计算成像、超分辨、光场、深度学习成像 | 深入 |
| 第15章 工程案例与选型实战 | 完整选型流程、调试诊断、问题排查 | 实践 |

### 阶段2：原子笔记拆解（从教程中提取核心概念/公式/设备）

- `10-concepts/`：每个核心概念一篇独立笔记（如「艾里斑」、「奈奎斯特频率」、「像圈」）
- `20-formulas/`：每个公式一篇独立笔记（含变量、适用条件、推导、示例）
- `40-devices/`：每类设备一篇独立笔记（含规格、选型要点、常见型号）
- `80-sources/`：标准、论文、厂商资料的来源索引

### 阶段3：双链网络与知识地图更新

- 所有学习章节之间建立双向链接
- 学习章节链接到对应的概念/公式/设备笔记
- 概念/公式/设备笔记之间建立交叉引用
- 更新知识地图，包含完整路径和领域入口

## 执行计划

### Stage 1 — 进阶章节写作（10-12章）
部署写作子智能体，并行创建3章。

### Stage 2 — 深入+实践章节写作（13-15章）
基于Stage 1输出，创建剩余章节。

### Stage 3 — 原子笔记拆解
从10章中批量提取概念、公式、设备，创建原子笔记。

### Stage 4 — 双链与知识地图
更新知识地图，建立所有双向链接。

## 技能
- 使用 `report-writing` 的能力（结构化长篇写作）
- 使用 `deep-research-swarm` 的能力（光学进阶内容需要准确信息）
