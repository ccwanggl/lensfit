# 显微镜物镜

## 定义/概述
显微镜的核心成像部件，直接决定分辨率和放大倍率。

## 关键参数
| 参数 | 典型值 | 说明 |
|------|--------|------|
| 放大倍率 | 4× / 10× / 20× / 40× / 100× | 与目镜倍率组合得到总倍率 |
| 数值孔径 NA | 0.1–1.4 | 决定分辨率极限 |
| 工作距离 WD | 0.1–7mm | 高倍率通常WD更短 |
| 像差等级 | Achromat / Plan / Apo | 色差和平场校正级别 |

## 选型要点
- NA决定分辨率：根据瑞利判据，NA越高分辨率越好
- Plan要求平场：视场边缘与中心同样清晰，适合成像测量
- Apo要求色差控制：复消色差，适合多波段成像或高精度分析
- 油浸物镜：100×通常需油浸，NA可达1.3–1.4

## 常见误区
- **错误**：放大倍率越高越好，应该尽量选最高倍率
- **事实**：分辨率由NA决定，空有高倍率而无高NA只会放大模糊细节
