# 衍射光栅

## 定义/概述

衍射光栅（Diffraction Grating）是表面刻有周期性精细结构的平面或曲面光学元件，利用**多缝衍射**原理将不同波长的光在空间上分离，是光谱仪的核心色散元件。

按工作原理可分为透射式和反射式；按面型分为平面光栅和凹面光栅；按制造工艺分为刻划光栅和全息光栅。

## 关键参数

| 参数 | 符号 | 典型范围 | 说明 |
|------|------|----------|------|
| 刻线密度 | — | 30 ~ 4800 线/mm | 刻线密度越高，角色散越大 |
| 光栅常数 | d | 1/刻线密度 | 相邻刻线间距，单位 nm |
| 闪耀角 | θ_B | 0° ~ 60° | 使特定波长和级次的衍射效率最大的角度 |
| 闪耀波长 | λ_B | 紫外 ~ 红外 | 在闪耀角下效率最高的波长 |
| 波长范围 | λ | 深紫外 ~ 远红外 | 取决于材料和镀膜 |
| 衍射效率 | η | 20% ~ 80% | 特定波长/级次的衍射光功率占比 |
| 鬼线 | — | < 0.1% ~ 1% | 刻划误差导致的虚假谱线强度 |
| 总刻线数 | N | 10³ ~ 10⁵ | 光栅有效宽度 × 刻线密度，决定分辨率 |
| 尺寸 | — | 10 × 10 mm² ~ 110 × 110 mm² | 越大分辨率越高，但成本也越高 |

## 类型对比

| 分类维度 | 类型 | 特点 | 典型应用 |
|----------|------|------|----------|
| **光路** | 反射式 | 效率高、无材料吸收限制、更常用 | 大多数光谱仪 |
| | 透射式 | 结构紧凑、可低成本复制 | 小型光谱仪、教学设备 |
| **面型** | 平面光栅 | 需配合准直和聚焦镜 | 常规光谱仪 |
| | 凹面光栅 | 兼具色散和聚焦功能，简化光路 | 罗兰圆光谱仪、小型光谱仪 |
| **工艺** | 刻划光栅 | 三角形槽型、闪耀效率高 | 精密光谱仪 |
| | 全息光栅 | 正弦槽型、杂散光低、无鬼线 | 激光器、拉曼光谱仪 |
| | 复制光栅 | 低成本、批量一致性好 | 工业光谱仪、消费电子 |

## 选型要点

1. **刻线密度**：高刻线密度（如 1200+ 线/mm）色散大、分辨率高，但自由光谱范围窄；低密度（如 300 线/mm）适合宽波段低分辨率。
2. **闪耀波长/角**：选择与应用波段匹配的闪耀波长，使目标波段效率最高。
3. **波长范围**：紫外光栅常用 MgF₂ 或铝镀膜；红外光栅需特殊基底和镀金。
4. **尺寸与分辨率**：大光栅（宽照明区）总刻线数 N 大，理论分辨率高（R = mN）。
5. **衍射效率曲线**：光栅效率随波长和级次变化，需查看效率曲线确保目标波段效率足够。
6. **鬼线与杂散光**：精密光谱分析（如拉曼）需要低杂散光的全息光栅。
7. **温度稳定性**：高精度应用需考虑光栅热膨胀导致的波长漂移。

## 常见误区

1. **光栅效率 100%**：任何光栅都有效率曲线，非闪耀波段效率可能很低，且部分能量分散到多级次。
2. **刻线密度越高越好**：高密度光栅衍射角大，对光学系统设计和装调要求高，且自由光谱范围窄。
3. **零级衍射无用**：零级是镜面反射，无色散，但有时用于波长校准或光路对准。
4. **光栅无偏振依赖**：光栅效率与偏振态（S/P）强烈相关，S 偏振和 P 偏振效率不同。
5. **凹面光栅无像差**：凹面光栅简化光路但引入像差，高端光谱仪需用像差校正凹面光栅。
