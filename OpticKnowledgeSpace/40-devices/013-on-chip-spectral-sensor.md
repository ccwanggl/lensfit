# 片上光谱传感器

片上光谱传感器把谱选择或谱编码结构与光电探测器集成在芯片、焦平面或紧凑模组里，用来替代传统光谱仪中的狭缝、光栅、棱镜和扫描机构。它通常不直接给出“真实光谱”，而是先得到多通道或编码后的响应，再通过标定矩阵和重建算法得到光谱、指数、分类结果或物理量。

这类器件适合便携、低成本、快照、在线检测和嵌入式设备。不适合把实验室高精度光谱仪的全部能力原样搬到芯片上。

## 常见形态

| 形态 | 结构 | 适合任务 | 主要限制 |
| --- | --- | --- | --- |
| MSFA + CMOS/InGaAs 焦平面 | 像元级多谱段滤光阵列 | 多光谱相机、工业分选、农业、便携检测 | 空间分辨率和通道数权衡 |
| Fabry-Perot 微腔阵列 | 不同腔长形成窄带通道 | SWIR/MWIR/LWIR 窄带检测 | 入射角敏感，工艺厚度控制困难 |
| 超表面编码传感器 | 纳米结构形成谱响应矩阵 | 薄型化、快照式、计算光谱成像 | 标定复杂，角度/偏振/工艺敏感 |
| 波导/硅光光谱仪 | AWG、微环、光子晶体等 | 点测量、通信、生化传感 | 与二维成像面阵结合不直接 |
| 新型材料谱探测器 | 量子点、二维材料、范德华结构等 | 宽谱或无滤片探测探索 | 长期稳定性和批量一致性待验证 |

## 选型参数

| 参数 | 看什么 | 备注 |
| --- | --- | --- |
| 波段 | VIS-NIR、SWIR、MWIR、LWIR | 波段先决定探测器材料和光学材料 |
| 通道数 | 实际有效谱通道，不只是标称数量 | 通道响应高度相关时，通道数价值会下降 |
| 光谱分辨率 | FWHM、中心波长间隔、可分辨谱特征 | 窄通道会降低光通量 |
| 空间分辨率 | 每个谱段可用像素数 | MSFA 方案尤其要看这个指标 |
| 帧率 | 是否能覆盖动态目标 | 多帧可调方案要考虑运动错位 |
| SNR / NEP / NETD | 低照度或红外场景的可靠性 | 红外热成像还要看 NETD |
| 标定方式 | 是否提供响应矩阵、温度补偿和批次校正 | 计算型传感器离不开标定 |
| 角度敏感性 | 入射角变化会不会导致谱漂移 | FP 微腔和超表面路线都要重点看 |
| 封装与温控 | 是否制冷，是否需要恒温 | MWIR/LWIR 成本常由这里决定 |
| 软件支持 | 重建 SDK、数据格式、标定文件、示例代码 | 采购时应和硬件一起评估 |

## 选型流程

1. 明确任务输出：分类、识别、指数计算、温度估计、气体检测，还是完整光谱重建。
2. 确定波段：可见光/NIR 用硅基路线较自然，SWIR 常看 InGaAs，MWIR/LWIR 要把制冷和热背景计入成本。
3. 判断是否必须快照：动态目标优先 MSFA、超表面或少帧调制；静态目标可以接受扫描或可调方案。
4. 查看目标谱特征宽度：宽谱特征不需要过窄通道；窄吸收峰需要更高分辨率和更严格标定。
5. 要求供应商提供响应曲线和标定条件：至少包含每个通道的中心波长、FWHM、透过率、角度/温度漂移和串扰。
6. 用真实样品做验证：不要只看标准色卡或演示数据，最好覆盖照明变化、温度变化和批次差异。

## 与传统光谱仪的差别

| 维度 | 片上光谱传感器 | 传统光谱仪 |
| --- | --- | --- |
| 体积 | 小，易集成 | 通常较大 |
| 速度 | 快照或少帧方案可很快 | 扫描方案通常较慢 |
| 光谱精度 | 依赖通道设计和标定 | 高端仪器更稳定 |
| 光通量 | 受滤波/编码限制 | 可通过光路设计优化 |
| 成本 | 量产后有优势 | 高精度系统成本高 |
| 算法依赖 | 高 | 相对低 |
| 适合任务 | 嵌入式、在线、便携、任务驱动 | 标准测量、实验室、高精度定量 |

## 常见风险

1. 只看通道数，不看响应矩阵。高相关通道对重建帮助有限。
2. 忽略照明。反射式多光谱测到的是光源、样品反射率和系统响应的乘积。
3. 忽略角度。微腔和超表面在大视场下可能出现中心波长漂移。
4. 把样机论文性能当成量产指标。纳米结构和微腔阵列的一致性需要单独验证。
5. 没有重建和标定预算。很多片上方案的真实工作量在软件、标定和数据闭环上。
