# LensFit 光学知识库重构规划：从线性章节到微专业模块

> **版本**：v1.0
> **日期**：2026-07-07
> **依据**：微专业方法论（`deep-research-report.md`）
> **目标**：将现有知识库从"16章线性结构"重构为"五模块环形微专业"，同时保留 Obsidian 双链网络。

---

## 执行摘要

本次重构的核心是：**保持内容资产不变，重组导航与学习逻辑**。现有知识库的 16 章教程、80+ 概念/公式/设备笔记、交互式应用和知识地图是宝贵资产，不需要重写，但需要按微专业的五模块体系重新编排。

**五模块微专业**：

- 模块甲 → 模块乙 → 模块丙 → 模块戊
- 模块乙 → 模块丁 → 模块戊
- 模块戊 → 综合项目

**重构原则**：
1. **内容不动，索引重组**：优先通过模块 README 和索引文件实现环形导航，减少对物理文件移动的依赖。
2. **链接保护**：保留原有文件路径，新增模块目录作为"视图层"；如必须移动，使用 Obsidian 内置移动功能（自动更新链接）。
3. **渐进迁移**：允许新旧结构并行运行，逐步淘汰旧结构。
4. **三本账贯穿**：每个模块维护概念账、计算账、项目账。

## 任务2：目录重构（Directory Restructure）

### 2.1 设计原则

重构采用**"视图层优先，物理层渐进"**的策略：

1. **阶段一（本期）**：新建模块目录作为"视图层"，原有文件不动，通过模块 README 和索引文件实现环形导航。
2. **阶段二（远期）**：根据使用反馈，逐步将概念/公式/设备笔记物理移动到对应模块目录，原有目录保留重定向 stub。
3. **阶段三（远期）**：完全切换到新结构，旧目录标记为 `deprecated`。

这种策略的好处：
- **零链接破坏**：原有 `[[path/file]]` 链接全部有效。
- **可回滚**：如果新结构不好用，随时可以回到旧结构。
- **可并行**：新旧学习路线可以同时存在，供不同用户选择。

### 3.3 模块关键习题

> 以下习题从微专业方法论报告提取，与现有 `50-learning/009-exercises.md` 的对应关系已标注。

#### 模块甲｜桥接模块

1. **为什么说"波长、频率、能量"是学习光学时必须同时掌握的三个量？**
   > 答案要点：因为光既可作为波讨论传播与干涉，也常用光子能量讨论与物质相互作用；波长决定空间尺度直觉，频率决定振荡快慢，能量则与吸收/发射过程直接相关，它们之间可通过基本关系互相换算。

2. **为什么零基础学习者也要尽早接受"折射率不是材料标签，而是传播参数"的说法？**
   > 答案要点：因为折射率会直接进入折射、传播速度、成像位置和色散讨论；把它仅当作"玻璃种类编号"会阻断你理解成像与波动统一框架。

3. **为什么薄透镜公式能作为光学入门的第一公式，但不能作为全部光学的核心？**
   > 答案要点：它在近轴、理想、单透镜近似下极其高效，适合建立一阶成像直觉；但一旦进入大孔径、宽视场、衍射极限和真实多片系统，就必须引入像差、波动与像质评价。

4. **什么叫"导数在光学里只要会用，不必一开始会严密证明"？**
   > 答案要点：对初学者更重要的是把导数看成"某个光学量对另一个量的敏感度或变化率"，比如位置—波长映射的斜率、像差随孔径变化的趋势，而不是先做严格数学证明。

5. **为什么这份微专业要把 Python/作图能力放在最前面？**
   > 答案要点：因为现代光学学习离不开可视化和仿真；RayOptics、POPPY 以及 Ansys 教学资源都默认学习者会读图、看曲线和解释仿真结果。

#### 模块乙｜几何光学与一阶成像

1. **为什么同样是"看远处"，相机、望远镜和显微镜的设计思维却不同？**
   > 答案要点：因为三者虽都属于成像系统，但目标物距、数值孔径、视场、像方要求和最终探测/观察方式不同；应用光学把这些典型系统单列，正是为了说明共同规律与差异化设计目标。

2. **孔径光阑为什么既影响亮度，又影响成像质量？**
   > 答案要点：孔径首先限制通光量和光束范围，从而影响照度；同时它也决定哪些边缘光线被接纳，因此会影响像差表现、景深和衍射极限。

3. **为什么"会画图"在应用光学里不是低级能力，而是核心能力？**
   > 答案要点：应用光学明确强调几何光学要重视画图，因为物像关系、光束限制、视场和孔径位置若不先图解，后面的尺寸与系统理解会非常抽象。

4. **为什么近轴成像是设计的起点而不是终点？**
   > 答案要点：近轴模型帮助你快速确定焦距、放大率、系统长度等一阶参数；但真实设计还要进一步考虑像差、照度、分辨率、畸变和制造误差。

5. **如何判断某个问题该先用几何光学还是直接上波动光学？**
   > 答案要点：若问题主要关心物像位置、放大率、视场、瞳和系统布局，通常先用几何光学；若关心分辨率、衍射、干涉、相位、PSF/MTF，则必须引入波动视角。

#### 模块丙｜波动光学、衍射与傅里叶成像

1. **为什么"相干"是很多初学者在干涉问题里最容易忽略、却又最关键的前提？**
   > 答案要点：因为干涉图样不是"只要两束光相遇就有"，而是对相位关系稳定性有要求；MIT 现代光学课把 temporal/spatial coherence 放在干涉前，就是为了避免把干涉误认为纯几何重叠。

2. **为什么一个点物体经过系统后不会严格成"点"？**
   > 答案要点：因为真实光学系统受衍射及可能的像差限制，点物体会被映射成 PSF；Ansys 的 spectrometer theory 页面也明确用点源—模糊像来解释衍射限制。

3. **为什么傅里叶光学不是"数学炫技"，而是成像分析的压缩语言？**
   > 答案要点：因为透镜、孔径、衍射和频率响应在傅里叶框架里能被统一描述；Goodman 的教材和《信息光学》都把傅里叶变换当作成像频率分析的核心工具。

4. **为什么工业界如此重视 MTF，而不是只给一个"分辨率数字"？**
   > 答案要点：因为 MTF 把对比度随空间频率变化的信息保留下来，比单一分辨率数更能反映系统在不同细节尺度上的真实性能。Edmund 的教程明确指出 MTF 是比较系统性能的常用方法。

5. **为什么 4f 系统和空间滤波在入门阶段值得学？**
   > 答案要点：因为它让你第一次真正看到"图像—频谱—再成像"的关系，是从几何光学跨入信息光学最直观的桥。MIT 6.161 把 Fourier optics、classical two-lens processor 和滤波放在同一段课程中，正说明它的枢纽地位。

#### 模块丁｜光谱学与光谱仪

1. **为什么光谱相比普通图像更擅长回答"是什么"和"处于什么状态"这两个问题？**
   > 答案要点：因为图像主要给出空间形状与结构，而光谱记录了亮度随波长变化的细节，可用于推断组成、温度、密度和运动。NASA 的 Spectroscopy 101 对此解释得非常直接。

2. **为什么谱仪中的狭缝不能无限做宽？**
   > 答案要点：狭缝越宽通光量通常越大，但带宽会变宽、分辨率会下降；HORIBA 的 bandpass 说明明确把狭缝宽度作为影响 bandpass/FWHM 的关键因素之一。

3. **Czerny–Turner 结构为什么成为学习入门谱仪时的典型模板？**
   > 答案要点：因为它用"入射狭缝—准直镜—平面光栅—聚焦镜—探测器"的清晰链路，把分光、成像和机械调节逻辑展示得最直观。HORIBA 的说明页面明确给出了这一配置及其用途。

4. **为什么谱仪分辨率不能只靠"加长焦距"来无脑提升？**
   > 答案要点：因为更长焦距虽然会把谱拉得更开，但衍射斑和系统尺寸也会随之变化；Ansys 的 spectrometer theory 页面明确指出仅仅加大聚焦镜焦距并不会自动提高最终谱仪分辨率。

5. **为什么波长标定是任何实用光谱分析前都必须做的步骤？**
   > 答案要点：因为探测器原始输出常只是像元位置，只有把像元坐标映射到实际波长，峰位、峰宽和材料判断才有物理意义。Ansys 的示例专门给出了 detector position 到 wavelength 的映射函数讨论。

#### 模块戊｜光学设计、像差与像质评价

1. **为什么真正的光学设计不是"把焦距定出来"就结束？**
   > 答案要点：因为真实设计必须同时满足视场、孔径、像质、结构尺寸、制造成本和容差要求；设计课程把像质评价、像差理论、设计软件和典型系统设计放在同一门课里，就是因为这些因素必须联立考虑。

2. **为什么零基础做设计时最适合从单透镜系统开始？**
   > 答案要点：Ansys 的 Basic Lens Design 明确说明单透镜 sequential 模式教程面向 complete beginners，且足以建立光学设计原则的实践基础。

3. **为什么像差学习既要看"几何图像"，又要看"波前语言"？**
   > 答案要点：几何图像便于直观看到模糊形态，波前语言则更适合统一分析与优化；Mahajan、Sasián 和 RayOptics/POPPY 等资源共同说明了从几何到波前的双重视角是现代像质分析的基础。

4. **为什么 MTF、Spot diagram、distortion、relative illumination 不应孤立看？**
   > 答案要点：因为它们分别反映对比度传递、点像扩展、几何保真和能量分布，单看任何一个都可能误判系统整体可用性。Edmund 对 MTF 的解释和设计课程对像质评价的定位都支持这一点。

5. **什么时候应该用开源工具，什么时候应该用工业软件？**
   > 答案要点：当目标是理解原理、快速试算和低成本入门时，用 RayOptics/POPPY 很合适；当目标转向行业流程、复杂优化和容差分析时，OpticStudio 或 CODE V 更接近工程实际。RayOptics 文档、Ansys 学生版说明和 CODE V 官方产品页共同表明了这种分层使用策略。

> **定义**：三本账是贯穿微专业的学习记录系统，要求学习者每个模块都要维护三个文档：概念账、计算账、项目账。这是从 MIT 项目实验课和 Ansys 入门轨道中提炼的学习方法。

#### 概念账（Concept Ledger）

每个模块的概念账是一个 Markdown 文件，记录该模块中遇到的所有术语、概念、单位和边界条件。格式如下：

```markdown
# 模块X 概念账

## 术语与定义
| 术语 | 定义 | 适用边界 | 关联概念 |
|------|------|---------|---------|
| 近轴近似 | 光线与光轴夹角很小，sinθ ≈ θ | 角度 < 5° | 理想成像、像差 |

## 常见误区
- 误区1：...
- 误区2：...

## 本章新知
- 新知1：...
```

#### 计算账（Computation Ledger）

每个模块的计算账记录所有常用公式、典型题型和计算过程。格式如下：

```markdown
# 模块X 计算账

## 公式卡片
| 公式 | 表达式 | 变量 | 单位 | 适用条件 | 例题 |
|------|--------|------|------|---------|------|
| 薄透镜高斯 | 1/f = 1/u + 1/v | f,u,v | mm | 近轴/薄透镜 | ... |

## 典型题型与解法
### 题型1：已知WD/FOV/s求焦距
- 解法：先算放大率，再用焦距反推公式
- 例题：...

## 我的计算练习
- 练习1：...（含过程和结果）
```

#### 项目账（Project Ledger）

每个模块的项目账记录仿真脚本、实验照片、误差分析和阶段总结。格式如下：

```markdown
# 模块X 项目账

## 项目1：xxx
- 目标：...
- 工具：...
- 脚本路径：...
- 结果：![[...]]
- 误差分析：...
- 阶段总结：...
```

### 4.5 综合项目（Capstone Projects）

完成全部五个模块后，学习者需要选择一个综合项目作为收尾。综合项目要求把至少两个模块的知识连接起来，并产出一份可复现、可解释、指标清晰的报告。

#### 综合项目一：单透镜成像系统设计与分析

- **连接模块**：模块乙（几何光学）+ 模块丙（波动/MTF）+ 模块戊（像质评价）
- **任务**：
  1. 确定系统规格（视场、工作距离、传感器、F/#）
  2. 用近轴计算确定焦距和初步结构
  3. 在 RayOptics/OpticStudio 中搭建模型
  4. 分析 Spot diagram、MTF、畸变、照度
  5. 讨论衍射限制与像差限制各自的贡献
  6. 提出改进建议（如是否需要胶合、是否需要非球面）
- **产出**：完整设计报告（含系统需求、结构图、关键参数、像质评价、问题与改进建议）
- **预计时间**：15-20 小时
- **难度**：高

#### 综合项目二：简易可见光谱仪

- **连接模块**：模块丁（光谱学）+ 模块乙（光学结构）+ 模块戊（设计闭环）
- **任务**：
  1. 确定光谱范围、分辨率、探测器规格
  2. 选择分光元件（光栅/棱镜）并计算色散角
  3. 设计 Czerny-Turner 或透射式结构
  4. 计算狭缝宽度、焦距、探测器尺寸与分辨率的关系
  5. 做波长标定（使用已知谱线，如汞灯/LED）
  6. 分析主要误差来源和限制
- **产出**：设计方案报告 + 结构草图 + 标定数据 + 误差分析
- **预计时间**：12-18 小时
- **难度**：中到高

#### 综合项目三：成像系统 MTF 与 PSF 对比分析

- **连接模块**：模块丙（波动/MTF）+ 模块乙（几何/像差）+ 模块戊（像质评价）
- **任务**：
  1. 选择三个不同 F/# 的镜头（或同一镜头不同光圈）
  2. 用 Python/POPPY 计算理想系统的 PSF 和 MTF
  3. 用几何光学近似估算像差贡献
  4. 对比"理想 MTF"与"实际 MTF"（从厂商数据或实测）
  5. 讨论"衍射限制"与"像差限制"在什么条件下切换主导
  6. 写出一份可复现的对比报告
- **产出**：对比报告 + Python 脚本 + 结果图表
- **预计时间**：10-15 小时
- **难度**：中

#### 综合项目四：片上多光谱成像系统分析（进阶）

- **连接模块**：模块丁（光谱）+ 模块乙（成像）+ 模块丙（计算光学）+ 模块戊（设计）
- **任务**：
  1. 选择一种片上多光谱技术路线（滤光片阵列、Fabry-Perot、超表面）
  2. 分析其光谱分辨率、空间分辨率、信噪比的权衡
  3. 与常规光谱仪做对比
  4. 讨论适用场景和限制
- **产出**：技术分析报告
- **预计时间**：15-20 小时
- **难度**：高（偏研究）

### 4.6 与现有 CMOS Sensor Lab 交互式应用的整合方案

`.compute/cmos_sensor_lab/` 是现有知识库中最重要的交互式应用。它是一个基于 Streamlit 的 CMOS 传感器教学实验，包含以下模块：

- 光电转换链路（Photon → Electron → DN）
- 噪声模型与 SNR
- 动态范围与 WDR
- 曝光控制（卷帘/全局快门）
- 图像伪影模拟

#### 整合方案

**现状定位**：CMOS Sensor Lab 是**跨模块的通用交互式资源**，不专属任何一个模块，而是被多个模块引用。

| Lab 模块 | 对应知识库模块 | 对应知识点 | 整合方式 |
|---------|--------------|---------|---------|
| 光电转换链路 | 模块甲（桥接） | 光子-电子-DN 基础 | 模块甲 `projects/` 链接到 Lab 入口 |
| 噪声模型与 SNR | 模块乙（几何） | 传感器噪声/读出噪声/动态范围 | 模块乙 `projects/` 链接到 Lab 第2模块 |
| 动态范围与 WDR | 模块乙（几何） | 动态范围/势阱容量 | 模块乙 `projects/` 链接到 Lab 第3模块 |
| 曝光控制 | 模块甲（桥接） | 全局快门/卷帘快门 | 模块甲 `projects/` 链接到 Lab 第4模块 |
| 图像伪影模拟 | 模块丙（波动） | 混叠/运动模糊 | 模块丙 `projects/` 链接到 Lab 第5模块 |

**具体操作**：

1. **在 `.compute/cmos_sensor_lab/` 中增加模块导航**：在 `app.py` 或 `README.md` 中注明"本 Lab 被模块甲、乙、丙引用"，并给出各模块的入口链接。

2. **在各模块的 `projects/README.md` 中引用 Lab**：
   ```markdown
   ## 交互式实验
   - [CMOS Sensor Lab — 光电转换链路](.compute/cmos_sensor_lab/app.py) — 模块甲
   - [CMOS Sensor Lab — 噪声模型](.compute/cmos_sensor_lab/app.py) — 模块乙
   - [CMOS Sensor Lab — 曝光控制](.compute/cmos_sensor_lab/app.py) — 模块甲
   ```

3. **在 `90-maps/007-Optics Lab.md` 中更新**：将 Optics Lab 知识地图更新为"模块-实验"对应关系，让学习者知道每个实验属于哪个模块。

4. **未来扩展**：考虑为其他模块开发类似的交互式应用：
   - 模块乙：几何光学光线追迹交互器（基于现有 `focal_length_trace.py` 扩展）
   - 模块丙：POPPY 衍射仿真 Web 界面
   - 模块丁：光谱仪参数计算器（狭缝-分辨率-焦距关系）
   - 模块戊：简单透镜设计参数优化器
