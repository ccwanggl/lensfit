# 评价函数（优化目标函数）

## 定义

评价函数（Merit Function，也称 Error Function 或 Optimization Target Function）是光学设计软件（如 Zemax、Code V、OSLO）中用于量化光学系统偏离理想状态程度的标量函数。优化算法通过最小化评价函数，自动调整系统的设计变量（曲率、厚度、材料等），使系统像质逐步趋近最优。

评价函数的一般形式：
$$
MF = \sum_{i} w_i \cdot (T_i - V_i)^2 + \sum_{j} w_j \cdot C_j^2
$$

其中：
- $T_i$：目标值（Target），如理想焦距、期望的后工作距离
- $V_i$：实际值（Value），由当前系统追迹计算得到
- $w_i$：权重（Weight），反映该指标的重要性
- $C_j$：约束项（Constraint），如边缘厚度、玻璃库限制、总长度限制

## 直观理解

评价函数就像“光学系统的成绩单”：
- **每个评价项** = 一门考试（如“焦距是否正确”、“球差是否足够小”）
- **实际值 $V_i$** = 考试得分
- **目标值 $T_i$** = 满分标准
- **权重 $w_i$** = 这门课在总分中的占比（如“焦距”可能占 30%，“色差”占 20%）
- **约束项 $C_j$** = 硬性及格线（如“总长度不能超过 100 mm”必须满足，否则设计不可制造）

**优化过程** = 不断调整系统的“学习习惯”（设计变量），使“总分”（评价函数）越来越低，最终接近零。

## 关键参数/公式

| 参数 | 符号 | 说明 |
|------|------|------|
| 评价函数值 | $MF$ | 标量，越小表示系统越接近理想状态 |
| 权重 | $w_i$ | 控制各像质指标的相对优先级 |
| 目标值 | $T_i$ | 用户期望达到的光学参数 |
| 实际值 | $V_i$ | 当前系统状态下的追迹计算结果 |
| 约束项 | $C_j$ | 必须满足的边界条件（如正边缘厚度） |
| 设计变量 | $x_k$ | 可自由调整的参数（曲率、厚度、材料、非球面系数） |

常见评价函数操作数（Operands）：
- **EFLY**：有效控制焦距
- **SPHA、COMA、ASTI**：控制 Seidel 像差系数
- **RMS WFE**：控制波前误差均方根
- **MTFT / MTFS**：控制特定频率下的切向/弧矢 MTF
- **TOTR**：控制总长度
- **CTGT / CTLT**：控制中心厚度大于/小于某值
- **EDVA**：控制边缘厚度避免负值

## 适用场景

- **初始结构优化**：从专利或库中选取初始结构，通过评价函数驱动向满足规格的方向优化。
- **像差平衡**：在多个像差之间寻找最佳平衡，如球差与色差、场曲与畸变之间的折中。
- **多态系统优化**：变焦系统、多波段系统中，不同状态下评价函数的加权组合。
- **公差灵敏度优化**：在评价函数中引入公差灵敏度项，使系统不仅像质好，而且对制造误差不敏感。
- **约束满足设计**：确保物理可实现性（如正边缘厚度、可用玻璃库、合理的后工作距离）。
- **全局优化**：使用遗传算法或模拟退火在评价函数 landscape 中搜索可能的全局最优解，避免陷入局部极小。

## 常见误区

1. **评价函数值越小 = 设计越好？** 不一定。评价函数是人为构建的，如果权重设置不合理，可能会过度优化某些指标而牺牲其他重要性能。需要结合像质图（Spot diagram、MTF）综合判断。
2. **所有像差都要降到零？** 不是。实际光学设计需要在多个像差之间进行平衡，有时允许某些像差存在以换取其他更重要的性能提升（如用大畸变换取平场度）。
3. **约束只是惩罚项？** 约束是硬边界，不满足约束的设计即使像质再好也无法制造。优化中通常给约束项极高的权重或使用拉格朗日乘子法。
4. **局部最优 = 全局最优？** 绝大多数光学优化问题是非凸的，容易陷入局部极小。复杂系统需要从多个初始结构出发，或使用全局优化算法。
5. **忽略制造可行性**：评价函数只优化理论像质，不考虑实际制造公差。必须在优化后加入公差分析，必要时返回调整评价函数。
