# 4f 系统

## 定义

4f 系统是由两个相同焦距 $f$ 的透镜按间隔 $4f$ 排列（物-透镜1-透镜2-像，各间距为 $f$）构成的经典光学信息处理系统。中间平面（两透镜之间、各距透镜 $f$）为傅里叶变换平面（频谱面），在此插入滤波器可实现对图像的空间频率选择。

结构布局：
```
物平面 P1 ──f── 透镜 L1 ──f── 傅里叶平面 P2 ──f── 透镜 L2 ──f── 像平面 P3
```

## 直观理解

4f 系统的核心思想是"分两步完成成像+滤波"：
1. 第一步透镜 L1 对输入图像进行傅里叶变换，在后焦面（频谱面）形成其空间频率分布。
2. 在频谱面插入空间滤波器（如圆形光阑、狭缝、相位板等），选择性地改变各频率成分的振幅或相位。
3. 第二步透镜 L2 对滤波后的频谱进行逆傅里叶变换，在输出面得到处理后的图像。

由于透镜间距为 $4f$，系统可形成无放大倍率的像（放大率 = -1），且保持图像的严格几何关系。

## 关键参数/公式

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 透镜焦距 | $f$ | mm | 两透镜焦距相同 |
| 系统总长 | $4f$ | mm | 物-像总距离 |
| 放大率 | $M$ | 无量纲 | $M = -1$（倒立、等大） |
| 频谱面位置 | — | — | 两透镜中间，距各透镜 $f$ |
| 空间频率坐标 | $f_x, f_y$ | mm⁻¹ | 频谱面位置与空间频率成比例：$f_x = x / (\lambda f)$ |

关键关系：
- 频谱面位置 $(x, y)$ 对应空间频率：$(f_x, f_y) = (x/(\lambda f), y/(\lambda f))$
- 最大可处理频率受透镜孔径限制。

## 适用场景

- **光学图像处理**：如边缘增强（高通滤波）、平滑（低通滤波）、方向选择（狭缝滤波）。
- **空间滤波**：去除周期性噪声、提取特定方向纹理。
- **光学相关器**：模式识别、光学卷积运算。
- **相位成像**：Zernike 相位对比、暗场成像等。
- **光学加密与信息隐藏**：利用频域相位编码。
- **教学演示**：直观展示傅里叶光学原理。

## 常见误区

- **认为 4f 系统必须严格等于 4f**：实际上只要满足两个透镜的后焦面/前焦面共面即可，但标准 $4f$ 布局最简单直观。
- **忽略放大率 -1**：4f 系统产生倒像，如需正像需额外处理或接受倒像。
- **混淆滤波器位置**：滤波器必须放在准确的傅里叶平面（即透镜的共焦面），而非任意中间位置。
- **认为 4f 是严格无像差的**：实际透镜存在像差，精密应用中需选用消像差透镜或限制 NA。
- **忽略滤波器的衍射效应**：有限尺寸滤波器会引入额外的衍射效应，理想滤波分析需考虑此因素。
