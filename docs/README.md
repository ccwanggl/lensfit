# LensFit 知识库文档

> 本目录包含 LensFit 光学选型系统配套的领域知识文档，面向工程师、研究人员与爱好者，提供系统性的科普性参考。

---

## 文档目录

| 文档 | 领域 | 内容概要 |
|------|------|---------|
| [工业视觉](industrial-vision.md) | Industrial Vision | 工业镜头与传感器选型原理、像素精度、奈奎斯特采样、像圈覆盖、典型应用配置 |
| [摄影](photography.md) | Photography | 摄影镜头与传感器成像原理、焦段选择、景深控制、画幅对比、创作应用指南 |
| [红外成像](infrared-imaging.md) | Infrared Imaging | 热成像与SWIR光学原理、黑体辐射、NETD、探测器类型、材料波段匹配、测温应用 |
| [显微镜](microscopy.md) | Microscopy | 光学显微镜成像原理、瑞利分辨率、数值孔径、物镜色差校正、数码显微镜匹配逻辑 |

---

## 阅读建议

- **初学者**：建议从 [工业视觉](industrial-vision.md) 开始，因其公式和概念最为通用。
- **摄影师**：直接阅读 [摄影](photography.md) 的"典型应用场景"章节。
- **研发工程师**：建议通读全部文档，尤其关注各领域的"匹配逻辑"章节。
