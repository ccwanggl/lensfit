# 第7章 接口与安装

> "再好的镜头和传感器，如果装不到一起，就只是一堆昂贵的金属和玻璃。"

---

## 7.1 直觉：为什么有些镜头装不上？

想象你买了一个新灯泡，回家发现：
- 灯泡是 E27 螺口，灯座是 E14 → 太大了，拧不上
- 灯泡是卡口式，灯座是螺口 → 结构完全不同

相机镜头和机身的接口关系也一样。**接口（Mount）** 就是镜头和机身之间的「机械契约」——规定了法兰距、直径、卡口结构、电子触点等。

---

## 7.2 法兰距（Flange Distance）

### 直觉：投影仪到屏幕的距离

想象一个投影仪：
- 把投影仪放在离墙 2m 的地方 → 画面清晰
- 把投影仪移到离墙 1m 的地方 → 画面模糊（失焦）
- 把投影仪移到离墙 3m 的地方 → 画面也模糊

镜头的法兰距就是类似的概念：**镜头后端到传感器感光面的距离必须精确匹配设计值**，否则无法合焦。

### 常见接口的法兰距

| 接口 | 法兰距 (mm) | 典型应用 |
|------|------------|---------|
| **索尼 E** | 18.0 | 索尼/适马/腾龙无反 |
| **佳能 RF** | 20.0 | 佳能无反 |
| **尼康 Z** | 16.0 | 尼康无反 |
| **M4/3** | 20.0 | 奥林巴斯/松下 |
| **徕卡 M** | 27.8 | 徕卡旁轴 |
| **C-mount** | 17.526 | 工业相机、显微镜 |
| **CS-mount** | 12.526 | 小型工业相机 |
| **佳能 EF** | 44.0 | 佳能单反 |
| **尼康 F** | 46.5 | 尼康单反 |
| **宾得 K** | 45.46 | 宾得单反 |
| **F-mount** | 46.5 | 尼康工业大面阵 |
| **M42** | 45.5 | 螺口通用 |
| **PL** | 52.0 | 电影镜头 |

> **记住这个数字**：C-mount = 17.526mm，CS-mount = 12.526mm，差 5mm。

## 7.3 转接环的物理原理

### 核心规则

> **长法兰距镜头 → 可以转接到短法兰距机身**（加垫片/转接环）
> 
> **短法兰距镜头 → 不能转接到长法兰距机身**（无法合焦）

### 为什么？

假设你有一个法兰距 46.5mm 的尼康 F 镜头，想装到法兰距 18mm 的索尼 E 机身上：

```
镜头设计：像平面应在镜头后端 46.5mm 处
机身设计：传感器在机身卡口后 18mm 处
差距：46.5 - 18 = 28.5mm

解决：加一个 28.5mm 的转接环，让镜头离传感器更远
```

反过来，索尼 E 镜头（18mm）装到尼康 F 机身（46.5mm）：

```
镜头设计：像平面应在镜头后端 18mm 处
机身设计：传感器在机身卡口后 46.5mm 处
差距：需要把像平面往前推 28.5mm

问题：光线只能往后传播，不能把传感器往前推
结论：无法转接
```

### 常见转接方案

| 镜头 | 机身 | 是否可行 | 方式 |
|------|------|---------|------|
| 佳能 EF → 索尼 E | ✅ | 转接环（28mm） |
| 尼康 F → 佳能 RF | ✅ | 转接环（24.5mm） |
| 徕卡 M → 索尼 E | ✅ | 转接环（10mm） |
| 索尼 E → 佳能 EF | ❌ | 不可能 |
| C-mount → CS-mount | ✅ | 加 5mm 垫片 |
| CS-mount → C-mount | ❌ | 不可能（除非改镜头） |

## 7.4 C-mount vs CS-mount

### 工业视觉中最常见的混淆

C-mount 和 CS-mount 看起来几乎一样——都是 1英寸直径的螺纹（每英寸 32 牙），但法兰距不同：

- **C-mount**：法兰距 17.526mm
- **CS-mount**：法兰距 12.526mm

### 三种组合

| 镜头 | 相机 | 结果 |
|------|------|------|
| C-mount 镜头 | C-mount 相机 | ✅ 完美匹配 |
| C-mount 镜头 | CS-mount 相机 | ✅ 加 5mm 垫片后可合焦 |
| CS-mount 镜头 | C-mount 相机 | ❌ 无法合焦（像平面在传感器后面） |
| CS-mount 镜头 | CS-mount 相机 | ✅ 完美匹配 |

> **实际场景**：很多工业相机是 CS-mount 的（因为可以做得更薄），但好镜头大多是 C-mount 的。所以厂家通常随相机附送一个 5mm 垫片，让你可以装 C-mount 镜头。

## 7.5 传感器尺寸与像圈匹配

### 全画幅镜头配 APS-C 机身

| 组合 | 结果 | 说明 |
|------|------|------|
| 全画幅镜头 + 全画幅机身 | ✅ 完美 | 像圈完全覆盖 |
| 全画幅镜头 + APS-C 机身 | ✅ 可用 | 只用到镜头中心区域，通常画质更好 |
| APS-C 镜头 + 全画幅机身 | ⚠️/❌ | 像圈不足，边缘严重暗角 |

> **为什么全画幅镜头配 APS-C 反而画质更好？**
> 因为镜头的像质通常是中心好于边缘。APS-C 只用到中心约 40% 的区域，避开了边缘最差的像质区。

### 工业镜头的像圈标注

工业镜头通常直接标注像圈直径：
- 像圈 11mm → 刚好覆盖 2/3" 传感器（对角线 11mm）
- 像圈 16mm → 覆盖 1" 传感器
- 像圈 22mm → 覆盖 4/3" 传感器

> **购买工业镜头时**：确认镜头像圈 ≥ 传感器对角线 × 1.05（留 5% 裕量）

## 7.6 电子触点与功能

### 现代镜头接口不仅有机械结构

除了机械连接，现代镜头接口还有：
- **电子触点**：传递光圈值、焦距、对焦距离信息
- **自动对焦马达驱动**：机身通过触点驱动镜头马达
- **防抖通信**：机身和镜头防抖系统协同工作

### 转接后的功能损失

用转接环转接时：
- ✅ 机械连接 → 永远可用
- ⚠️ 电子通信 → 取决于转接环是否带芯片
- ❌ 自动对焦 → 通常失效（除非高端电子转接环）
- ❌ 防抖 → 通常失效
- ❌ 机身控制光圈 → 通常失效（镜头变为手动光圈）

> **工业视觉场景**：几乎都是手动光圈、手动对焦，所以机械转接环就足够了。

## 7.7 显微镜的接口系统

### 显微镜与相机的连接

显微镜不是直接装相机，而是通过 **C-Mount 适配器（TV adapter）**：

```
显微镜筒（无限远校正） → 镜筒透镜 → C-Mount 适配器 → 相机
```

### 适配器倍率

适配器的倍率决定了相机看到的视场大小：

| 适配器倍率 | 适用传感器 | 说明 |
|-----------|-----------|------|
| 0.5× | 1/2.3"、1/3" | 小传感器专用 |
| 0.63× | 2/3" | 最常用 |
| 1× | 1"、4/3" | 大传感器 |

**总放大倍率到相机**：

$$
\beta_{camera} = M_{objective} \times M_{adapter}
$$

> **例子**：40× 物镜 + 0.63× 适配器 → 相机端放大倍率 = 25.2×

## 7.9 常见误区

### 误区1：「C-mount 和 CS-mount 镜头可以互换」

**错误**：认为拧上去就能用。

**事实**：CS-mount 镜头装到 C-mount 相机上，像平面在传感器后面 5mm，完全无法合焦。反过来（C 镜头 + CS 相机）加 5mm 垫片可以。

### 误区2：「转接环不影响画质」

**错误**：认为转接环只是一圈金属，不影响光学质量。

**事实**：
- 劣质转接环可能导致镜头倾斜（光轴不正）
- 转接环厚度不精确会影响法兰距，导致对焦偏移
- 长转接环可能引入杂光反射

**正确做法**：购买有品牌保障的转接环，厚度公差 < 0.05mm。

### 误区3：「接口一样就能装」

**错误**：认为都是 C-mount 就一定能匹配。

**事实**：除了法兰距，还有：
- 像圈是否覆盖传感器
- 后组镜片是否会碰到传感器保护玻璃
- 镜头的后焦距（Back Focal Length）是否足够

**Q1**：一个法兰距 45.5mm 的 M42 镜头，能否转接到法兰距 18mm 的索尼 E 机身上？需要多长的转接环？
<details>
<summary>点击展开答案</summary>

可以。转接环长度 = 45.5 - 18 = **27.5mm**。这是一个常见的 M42→E 转接环规格。

</details>

**Q2**：为什么 CS-mount 镜头不能直接装到 C-mount 相机上？
<details>
<summary>点击展开答案</summary>

CS-mount 法兰距（12.526mm）比 C-mount（17.526mm）短 5mm。CS 镜头装到 C 机身上时，像平面会在传感器后面 5mm 处，光线还没聚焦就打到传感器上了，所以整段距离内都无法合焦。

</details>

**Q3**：显微镜 40× 物镜，配 0.5× 适配器，相机传感器看到的放大倍率是多少？
<details>
<summary>点击展开答案</summary>

$$\beta_{camera} = 40 \times 0.5 = 20×$$

即传感器上的像是标本的 20 倍大。

</details>
