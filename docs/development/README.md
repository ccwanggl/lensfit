## 维护约定

- `architecture/` 只描述已经落地或明确标为目标状态的设计。
- `decisions/` 使用 `ADR-NNNN-title.md` 命名，并记录状态、背景、决策和后果。
- `plans/active/` 中的计划完成后移入 `plans/archive/`。
- `reviews/` 按日期命名，保留复核批注，不覆盖原始发现。
- `releases/` 记录构建环境、迁移版本、测试结果和发布产物。
