# 模块乙项目清单（几何光学）

> 对应模块：[[模块乙：几何光学]]  
> 目标：通过实践掌握光线追迹、近轴光学、像差分析与照明设计。

---

## 项目一：薄透镜光线追迹器

- **目标**：用 Python 或 MATLAB 实现近轴光线追迹程序，支持单透镜与双透镜系统，计算主点、焦点、放大率与像面位置。
- **预计时间**：6–10 小时
- **所需工具**：Python（NumPy）或 MATLAB / Excel
- **产出物**：光线追迹代码、光路图、系统参数计算表
- **关联内容**：[[近轴光学]]、[[高斯光学]]、[[光线追迹]]

---

## 项目二：简单成像系统搭建与测量

- **目标**：利用光学平台（或仿真环境）搭建单透镜成像系统，实测物距、像距、放大率，并与近轴理论对比。
- **预计时间**：4–6 小时（实验）/ 3–4 小时（仿真）
- **所需工具**：光学平台（透镜、光具座、CCD）或 Zemax / Code V 仿真
- **产出物**：实验数据表、误差分析、成像质量评估
- **关联内容**：[[薄透镜公式]]、[[放大率]]、[[景深]]

---

## 项目三：像差分析实验

- **目标**：通过 Zemax 或实际光学系统测量/仿真球差、彗差、像散与畸变，绘制各像差随孔径/视场的变化曲线。
- **预计时间**：8–12 小时
- **所需工具**：Zemax OpticStudio / Code V / 实际光学系统
- **产出物**：像差曲线图、点列图（Spot Diagram）、波前图
- **关联内容**：[[球差]]、[[彗差]]、[[像散]]、[[畸变]]、[[赛德尔像差]]

---

## 项目四：照度分布计算与验证

- **目标**：模拟点光源、朗伯面光源在接收面上的照度分布，考虑距离平方反比定律与余弦定律，与实验测量或标准数据对比。
- **预计时间**：4–6 小时
- **所需工具**：Python / MATLAB / LightTools 或 TracePro
- **产出物**：照度分布图、理论计算与仿真对比表
- **关联内容**：[[照度]]、[[朗伯体]]、[[余弦定律]]、[[距离平方反比定律]]
