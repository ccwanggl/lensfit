# 模块戊项目清单（光学设计）

> 对应模块：[[模块戊：光学设计]]  
> 目标：通过实践掌握光学设计流程、优化方法与公差分析。

---

## 项目一：单透镜球差优化

- **目标**：在 Zemax 或 Code V 中设计单透镜（BK7 玻璃），通过改变曲率半径使球差最小化，对比不同形状因子（bending factor）下的球差变化。
- **预计时间**：6–8 小时
- **所需工具**：Zemax OpticStudio / Code V / Oslo
- **产出物**：优化前后光路图、球差曲线、点列图、波前图
- **关联内容**：[[球差]]、[[Zernike 多项式]]、[[波前误差]]、[[评价函数]]

---

## 项目二：双胶合消色差透镜设计

- **目标**：设计一个双胶合透镜（ crown + flint 玻璃组合），在可见光波段（F、d、C 线）实现轴向色差校正，满足给定焦距与 NA 要求。
- **预计时间**：8–12 小时
- **所需工具**：Zemax OpticStudio / Code V
- **产出物**：设计报告、光路图、色差曲线、场曲/畸变图
- **关联内容**：[[色差]]、[[阿贝数]]、[[部分色散]]、[[评价函数]]

---

## 项目三：显微镜物镜设计（有限远/无限远）

- **目标**：设计一个 10× 或 20× 显微镜物镜，满足给定 NA 与工作距离，评估分辨率与像差校正水平。
- **预计时间**：12–16 小时
- **所需工具**：Zemax OpticStudio / Code V
- **产出物**：设计报告、系统参数表、MTF 曲线、点列图、波前图
- **关联内容**：[[数值孔径]]、[[分辨率]]、[[瑞利判据]]、[[Strehl 比]]

---

## 项目四：光学系统公差分析

- **目标**：对已有光学系统（如项目二或项目三）进行公差分析，确定各面曲率、厚度、偏心、倾斜的敏感度，设计补偿器与装配方案。
- **预计时间**：8–10 小时
- **所需工具**：Zemax OpticStudio / Code V
- **产出物**：公差分析表、敏感度排序、 Monte Carlo 模拟结果、补偿方案
- **关联内容**：[[公差分析]]、[[敏感度]]、[[补偿器]]、[[Strehl 比]]、[[RMS 波前误差]]

---

## 项目五：Zernike 多项式波前拟合

- **目标**：利用 Python 或 MATLAB 实现 Zernike 多项式拟合程序，从干涉图数据中提取波前误差系数，绘制各阶像差贡献图。
- **预计时间**：8–12 小时
- **所需工具**：Python（NumPy / SciPy）或 MATLAB
- **产出物**：Zernike 拟合代码、波前重建图、各阶系数柱状图、像差分析报告
- **关联内容**：[[Zernike 多项式]]、[[波前误差]]、[[Strehl 比]]、[[RMS 波前误差]]
