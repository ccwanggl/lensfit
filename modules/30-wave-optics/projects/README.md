# 模块丙项目清单（波动光学）

> 对应模块：[[模块丙：波动光学]]  
> 目标：通过实践掌握干涉、衍射、傅里叶光学与空间滤波。

---

## 项目一：双缝干涉仿真

- **目标**：数值模拟杨氏双缝干涉实验，观察条纹对比度、间距与光源宽度/单色性的关系，验证时间相干性与空间相干性的影响。
- **预计时间**：6–8 小时
- **所需工具**：Python（NumPy / Matplotlib）或 MATLAB
- **产出物**：干涉条纹图、对比度随光源宽度变化曲线、相干性分析报告
- **关联内容**：[[相干]]、[[干涉]]、[[可见度]]、[[空间相干性]]、[[时间相干性]]

---

## 项目二：菲涅尔衍射数值模拟

- **目标**：实现菲涅尔衍射的数值积分（或角谱法），模拟圆孔、直边、单缝的衍射图样，对比菲涅尔近似与夫琅禾费近似的适用条件。
- **预计时间**：8–12 小时
- **所需工具**：Python（NumPy / SciPy）或 MATLAB
- **产出物**：衍射图样动画（随传播距离变化）、强度分布曲线、近似条件分析
- **关联内容**：[[菲涅尔衍射]]、[[夫琅禾费衍射]]、[[角谱传播]]、[[傅里叶变换对]]

---

## 项目三：4f 光学系统与空间滤波

- **目标**：在仿真环境（如 Python 或 Zemax）中搭建 4f 系统，实现低通/高通/带通空间滤波，观察输入图像的频域处理效果。
- **预计时间**：8–12 小时
- **所需工具**：Python（NumPy / FFT）或 Zemax / 实际光学平台
- **产出物**：滤波前后图像对比、频谱图、截止频率与图像质量关系分析
- **关联内容**：[[4f 系统]]、[[空间滤波]]、[[截止频率]]、[[光学传递函数]]

---

## 项目四：光学传递函数（OTF/MTF）测量

- **目标**：利用狭缝/刃边法或正弦光栅法测量光学系统的 MTF，对比理论计算（如衍射极限 MTF）与实测结果。
- **预计时间**：10–14 小时
- **所需工具**：光学平台（狭缝、光栅、CCD）或 Zemax 仿真
- **产出物**：MTF 曲线、对比分析表、系统分辨率评估报告
- **关联内容**：[[调制传递函数]]、[[截止频率]]、[[分辨率]]、[[点扩散函数]]
